AYANEOの廉価ブランドKONKRが、縦型Androidハンドヘルド「Pocket Block」の予約受付をAYANEO公式ストアで始めた。2GB RAM版が89ドル、3GB RAM版(Atoms White)が109ドルで、いずれも$10引きの早期価格(79ドル/99ドル)が設定されている(掲載時点)。中国向けの出荷は10月15日から、海外向けは10月末の予定だ。**予約の段階であり、届くまでは製品として確定していない。**

## スペック

| 項目 | 内容 |
| --- | --- |
| 画面 | 3.33インチ LCD、4:3、960×720(360PPI) |
| SoC | MediaTek Helio G85 |
| OS | Android 12 |
| メモリ/ストレージ | 2GB/3GB、32GB/64GBの構成 |
| バッテリー | 3,500mAh |
| サイズ/重量 | 113.2×77.4×19.8mm/165g |
| 通信・端子 | Wi-Fi、Bluetooth、USB-C、3.5mmイヤホンジャック |
| 色 | Cube Purple、Original Grey、Atoms White(半透明) |

画面が4:3で正方形に近く、ゲームボーイ系の縦型筐体に収めているのが特徴。Helio G85はPSPやN64世代までが現実的な帯域で、PS2やGameCubeは荷が重いとRetro Dodoは見ている。AYANEOは「AI」を前面に出した製品として5月に予告していたが、今回確認できた資料から、AI機能の具体的な中身は読み取れなかった。

## 日本から見るとどうか

購入先は掲載時点でAYANEO公式ストアのみで、同社は当面、外部の小売店を使わない方針だとされる。日本語サイトのAYANEO Japanには、同ブランドのPocket FITは載っているが、Pocket Blockの掲載は確認できなかった。日本向けの発送可否、関税、保証の扱いは、いずれも確認できていない。

無線機能を持つため、技適が焦点になる。掲載時点で技適取得の情報は見つからず、取得済みとは言えない。Wi-FiやBluetoothを切って、オフラインでゲームを遊ぶだけなら電波法上の問題は生じにくいが、通信を使うなら国内販売が始まってから買うほうが安全だ。急ぎで小型のレトロ機がほしい場合は、国内発送で買える別機種で代替できる。

情報源は公式ストアとRetro Dodo、Notebookcheckで、いずれも同一の発表に基づく。価格・出荷時期は掲載時点のもの。
