1936年創業のフィンランドブランドSuuntoが、ランニングウォッチ「Suunto Run 2」を2026年9月8日に発売した。公式プレスリリースによれば、発売地域は「北米・欧州・アジア太平洋の主要市場」。価格はストレージ4GBモデルが349ドル、64GBモデルが399ドルで、カラーはAll Black・Feather Gold・Aloe Greenの3色。

## スペック(公式発表値)

| 項目 | 内容 |
|---|---|
| GPS/GNSS | L1+L5デュアルバンド(GPS・GLONASS・Galileo・BeiDou・QZSS) |
| ディスプレイ | 1.32インチAMOLED、最大輝度2,000ニト |
| バッテリー | 通常使用10日、高性能(デュアルバンド)モード24時間 |
| 心拍センサー | 12チャンネル光学式(手首) |
| 防水性能 | 5ATM |
| 重量/厚さ | 35g/11.7mm |
| ストレージ | 4GBまたは64GB |
| 価格 | 349ドル(4GB)/399ドル(64GB) |

## 世界地図をオフラインで、しかも無料で

最大の特徴は、世界中のオフライン地図を無料で使える点だ。スマートフォンが無い場所でもナビゲーションでき、音楽も本体に保存して単体で再生できる。競合の一部が地図やナビゲーション機能を上位モデルや有料プランに限定するのに対し、Suunto Run 2はこの価格帯でオフライン地図を標準搭載している。

## 日本から見るとどうか

Suuntoは電話サポート番号や取扱店検索ページを備えた日本語の公式サイト(suunto.com/ja-jp)を持ち、すでに国内でのブランド展開はある。実際、Suunto Run 2にも日本語の製品ページが用意されており、「今すぐ購入」のボタンも表示される。ただし価格欄は「読み込み中」のまま数値が表示されず、実際に決済まで進めるアジア太平洋向けストア(apac.suunto.com)を確認すると、Suunto Run 2はまだ掲載されておらず、前モデルの「Suunto Run」だけが並んでいる。つまり日本語ページは用意済みだが、日本で実際に買える段階には達していないとみられる。技適についても、公式発表に取得状況の記載は見当たらない。

デュアルバンドGPSとオフラインのフルカラー地図という組み合わせを今すぐ試したいなら、Garmin Forerunner 970が国内正規品として技適取得済みで販売されている。Suunto Run 2の日本発売を待つか、今使える選択肢に切り替えるかは、レースの予定次第だろう。
