8BitDoのレバーレス型コントローラー「Arcade Controller Pro」の予約開始が、9月の予定から10月に延びた。公式ページは「予約開始は10月」と表示している。価格は、掲載時点で公表されていない。

## 前作から何が変わったか

レバーレスは、スティックの代わりに方向入力も含めてすべてをボタンで行う格闘ゲーム用の形式だ。Proは前作のArcade Controllerより、ボタンを小さくして間隔を詰め、指が自然に届く配置にした。プログラム可能なボタンは4つから5つ（P1〜P5）に増え、左手の小指側にP5が付く。

本体左上に1.47インチの画面があり、入力の表示、電池残量の確認、SOCDなどの設定変更を、別のソフトなしで本体だけでできる。

| 項目 | 内容 |
| --- | --- |
| 対応 | Switch、Switch 2、PC |
| 接続 | Bluetooth（Switch）、2.4G（Windows）、有線 |
| 画面 | 1.47インチ。入力表示・電池残量・設定 |
| スイッチ | ホットスワップ対応の8BitDo Core Green（Kailh共同開発、リニア）。予備3個と引き抜き工具が本体内に入る |
| 天板 | 工具なしで外せる強化ガラスのフェイスプレート |
| ボタン表示 | SwitchとPCの配列を切り替えると表示が変わる |
| 付属 | 磁石式リストレスト、ロックキャップ5個（内部に収納） |

専用のダイヤルでは、接続モードの切り替え、音量と画面の調整、大会向けの「Tournament Lock」を操作できる。有線で使うときの抜けを防ぐケーブルロックと、2つのUSB-Cポートもある。

## 日本から見るとどうか

日本向けの販売や国内予約は、掲載時点で確認できていない。日本語で「8BitDo アーケードコントローラー Pro 国内 発売」を検索しても、国内の販売情報は見つからなかった。価格も出ていないので、国内価格との比較はまだできない。

技適については、総務省のデータベースで8BitDoの運営会社（Shenzhen 8Bitdo Tech）の登録がいくつか見つかるが、型式が英数字の記号で登録されており、このコントローラーに当たるものは特定できていない。Bluetoothと2.4Gの無線を使うので、国内で無線のまま使うなら、技適を確認してから買いたい。有線なら電波の問題は出ないが、その場合もこの製品の売りである画面やダイヤルは使える。

予約が始まるまで、買うかどうかは決められない。格闘ゲームをSwitch 2かPCで遊ぶ人は、価格の発表を待てばよい。
