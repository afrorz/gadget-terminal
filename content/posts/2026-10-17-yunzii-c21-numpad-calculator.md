キーボードメーカーのYunziiが、無線メカニカルテンキー「YUNZII C21」を発表した。テンキーでありながら電卓としても動き、上部の小さなTFT画面には好きな画像やGIFを表示できる。公式製品ページとTechPowerUpに載ったプレスリリースをもとに、仕様を整理する。

## 主な仕様

| 項目 | 内容 |
|---|---|
| レイアウト | 20%、18キー、TFT画面1枚 |
| 接続 | Bluetooth、2.4GHz無線、USB Type-Cの有線 |
| モード | キーボード、電卓、ゲーミング |
| スイッチ | Candy Linear／Sage Linear（3ピン・5ピンのホットスワップ式） |
| キーキャップ | 昇華印刷PBTのMOAプロファイル |
| 構造 | ガスケットマウント |
| バッテリー | 2,500mAh |
| 画面 | 428×142ピクセルのTFT |
| サイズ・重さ | 98.3×152.56×38.9mm、約250g |
| 色 | ピンク、ベージュ、パープル、コーヒー |

ほかに、キーの下のRGBと側面のライト、取り外せるフック、本体上部につくしっぽの飾り、本体内蔵のミニゲームがある。設定はWindowsとmacOSの専用ソフト、またはウェブ上のカスタマイズで行う。製品ページによれば、先着100注文には追加のチャーム（色はランダム）が付く。

## 使いどころ

メカニカルのテンキー単体という点は珍しくないが、電卓モードと画面表示を持つ点がC21の特徴になる。スイッチはリニア軸の2種類で、茶軸や青軸は選べない。ホットスワップ式なので、好みの軸に替えるのは前提として使える。

## 日本から見るとどうか

公式ストアの案内では、発送先は米国、カナダ、オーストラリア、英国で、それ以外の国は問い合わせとされている。日本への発送は、掲載時点で確認できなかった。価格も、公式ページとTechPowerUpのどちらにも載っていない。

技適は、型番が公開されておらず、総務省のデータベースで特定できなかった。Bluetoothと2.4GHz無線の2つを使う製品なので、国内で常用するなら、技適の表示がある国内向けの個体を待つのが安全だ。国内の取り扱いが始まるかどうかは、掲載時点で確認できていない。

待てない人は、国内で売られているBluetooth接続の電卓機能付きテンキーが代わりになるが、メカニカルスイッチの打鍵感やTFT画面は無い。
