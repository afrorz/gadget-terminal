BOOXが、シリーズで最も小さい電子書籍リーダー「Picco」の予約を2026年9月28日に公式ストアで始めた。3.97インチのモノクロE Inkを載せて重さは約58g、価格は99.99ドルから。出荷は11月の予定で、現時点では予約の段階にある。**予約は購入の確定ではなく、出荷時期は変わる可能性がある。**

## スペック

| 項目 | 内容 |
| --- | --- |
| 画面 | 3.97インチ モノクロE Ink、235PPI、色温度調整できるフロントライト |
| 操作 | タッチ、物理ページ送りボタン |
| 重さ | 約58g |
| ストレージ | microSDスロット(最大2TB)、16GBのカード付属 |
| バッテリー | 920mAh |
| 通信 | Wi-Fi、Bluetooth、USB-C |
| 付属品 | スマートフォンに取り付けられる磁気リング付きケース |
| 価格 | 99.99ドルから(予約、掲載時点) |

最大の違いはOSだ。BOOXの端末はAndroidを積むのが定番だったが、Piccoは軽量な独自OSで動き、新カテゴリ「BOOX Tiles」の第1弾と位置づけられている。デイリーガジェットはLinuxベースと伝えるが、公式資料はOSの名前を明記していない。Google Playは使えず、Kindleアプリなど他社の読書アプリも入れられない。本の転送は、専用アプリ「BOOX Tiles」、ウェブ、USB-Cで行う。ポモドーロ、ToDo、カウントダウンのアプリを標準で備える。

## 日本から見るとどうか

BOOX製品は国内ではSKT株式会社が正規代理店として扱っており、Amazon.co.jpや楽天市場でも購入できる。ただしPiccoについて、SKTの発売告知は掲載時点で確認できていない。購入先として確かなのは、米ドル建ての公式ストアだけだ。

Wi-FiとBluetoothを内蔵するので、技適が問題になる。技適取得の情報は掲載時点で確認できておらず、海外の公式ストアから個人輸入して無線機能を使うのは、取得を確認してからのほうがよい。国内の代理店が扱うなら、同社が販売するモデルは技適付きのはずだが、その発表を待つことになる。急ぎなら、国内正規品のPalma 2で近い使い勝手が得られる。
