Razerは11月5日、USB-C接続の有線ゲーミングイヤホン「Hammerhead V3 Chroma」を発表した。有線モデルでありながらアクティブノイズキャンセリング（ANC）を備え、両耳の外側がRazer Chroma RGBで光る。米国価格は79.99ドル、英国は79.99ポンド、欧州は89.99ユーロ。

## 主な仕様

| 項目 | 内容 |
|---|---|
| 接続 | USB-C（90度コネクター）。スマホ・タブレット・携帯ゲーム機・PC向け |
| ドライバー | 11mmダイナミック＋6mmツイーター |
| ノイズ対策 | フィードフォワード方式のANC |
| 操作 | インラインリモコンで音量・再生・ANC切り替え |
| マイク | 全指向性 |
| 防水 | IPX4（汗・雨・水しぶき） |
| 音づくり | ゲーム・音楽・映画・通話の4プリセット、カスタムEQ。PCではRazer Synapse経由でTHX 7.1サラウンド |
| ライティング | Chroma RGB、1,680万色 |
| 価格 | 79.99ドル / 79.99ポンド / 89.99ユーロ（掲載時点） |

イヤホン側に電池は無く、接続した端末から給電される。無線ではないため、Bluetoothの音声圧縮や遅延が入らないのが、Razerの言う利点だ。

## 90度コネクターの狙い

Razerは、真っすぐ飛び出すUSB-Cプラグが、スマホを横持ちしたときに手のひらに当たると説明している。V3 Chromaは直角に曲がった低背のコネクターで、対応する端末の側面に沿わせる作り。携帯ゲーム機のUSB-Cポートに挿して遊ぶ使い方を意識した設計だ。

注意点は、ANCの効きや音質の評価がまだ無いこと。ANCの数値（減衰量など）は公表されておらず、重量やケーブル長、本体色も今回の発表からは確認できていない。実機のレビューが出るまで、性能は判断できない。

## 日本で買える？使える？

無線機能が無い有線イヤホンなので、技適は関係なく、日本でそのまま使える。USB-Cを備えたスマホ・タブレット・携帯ゲーム機・PCにつなぐだけだ。

日本での発売について、Notebookcheckは12月、価格は14,280円と伝えている。ただしRazerの公式発表文には日本の価格が無く、確認できたのはこの1媒体だけ。国内で正式に案内されるまで待つのが確実だ。

待てない場合は、同じ系統で国内正規品が出ているモデルがある。ANCを重視するなら、ワイヤレスのHammerhead V3 HyperSpeed（21,980円・楽天・掲載時点）。有線で安く済ませるなら、ANCは無いがUSB-CにもつなげるHammerhead V3（7,980円・同）が選べる。
