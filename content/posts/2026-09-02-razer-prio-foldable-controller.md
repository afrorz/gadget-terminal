Razerが、折りたたむとクレジットカードほどの大きさになるモバイルゲーミングコントローラー「Prio」を発表した。折りたたみ時のサイズは107×67×23mm、重さ101g。開くとフルサイズのコントローラーになり、iPhone(iOS 18以降)・Android(14以降)の画面サイズ7インチまでの機種(iPhone 17 Pro Max、Galaxy S26 Ultraを含む)に装着できる。USB-C接続のみで完結し、ペアリングや専用バッテリーは不要。価格はRazerの発表文に記載が無く、Android Centralの実機レビューでは99ドルと報じられている。

## スペック

| 項目 | 内容 |
| --- | --- |
| 折りたたみ時サイズ | 107×67×23mm(クレジットカード程度) |
| 重量 | 101g |
| 対応機種 | iPhone(iOS 18以降)、Android(14以降)、画面7インチまで |
| 接続方式 | USB-C直結、ペアリング不要、バッテリー不要 |
| 操作系 | 静電容量式アナログスティック、4方向D-パッド、フェイスボタン、バンパー、トリガー |
| 対応ストリーミング | Xbox Cloud Gaming、Steam Link、PS Remote Play、Razer PC Remote Play |
| 価格(参考) | 99ドル(Android Centralの実機レビューによる、掲載時点で未確定) |

ボタン配置は十字キー、フェイスボタン、バンパー、トリガーを備えたフルサイズ構成。アナログスティックは物理的な接点を使わない静電容量方式を採用しており、Razerとして「ドリフト(意図しない誤入力)を抑える設計は初めて」とうたう。Razer Cortex Mobileボタンを押すとゲームライブラリを一発で開ける。ローカルプレイのほか、Xbox Cloud Gaming・Steam Link・PS Remote Play・Razer PC Remote Playでのストリーミングにも対応する。

## 日本から見るとどうか

掲載時点でRazer Prioの国内発売時期や取扱いは発表されていない。razer.comの日本サイトにもまだ掲載が確認できておらず、価格を含めて今後の案内を待つ段階だ。

技適については、PrioがBluetoothなどの無線通信機能を持たずUSB-C接続のみで動作する設計である点が手がかりになる。無線を発する機能が無ければ技適の対象になる可能性は低いとみられるが、これは仕様からの推測であり、Razer自身による確認は取れていない。

価格として出回っている99ドルも、Razer自身の発表文ではなくAndroid Centralの実機レビューに基づく数字である点には注意したい。確定した公式価格ではないため、円換算はもちろん、正式な価格として扱うのも時期尚早だ。

今日から同じ用途の製品が欲しい場合は、同じRazer製の「Kishi V2 for iPhone」が国内正規品として購入できる。折りたためない分かさばるが、USB-Cでスマホに直結して使うという基本設計はPrioと共通しており、対応機種を選ばず今すぐ試せる。
