Xiaomiが電動シェーバー「Mijia Electric Shaver S101 Cloud Pattern Blade Edition(雲紋刀頭版)」を発表し、2026年9月21日から中国のクラウドファンディングプラットフォーム「小米有品(Xiaomi Youpin)」で衆籌(クラウドファンディング)を開始した。衆籌価格は**105元(約15ドル)**、衆籌終了後の正規価格は**149元(約22ドル)**になる(いずれも掲載時点)。カラーはTwilight Blue(トワイライトブルー)とRock Gray(ロックグレー)の2色。

## 刃は金属射出成形(MIM)の二重リング構造

S101雲紋刀頭版の最大の特徴は刃網の構造だ。Gizmochinaの報道によれば、金属射出成形(MIM)によって刃網を二重リング状の紋様に成形しており、これが「雲紋(クラウドパターン)」という名前の由来になっている。凹型のステンレス刃と組み合わせることで、ひげを刃網に取り込んで巻き込むように切る構造だという。

本体は3枚の独立浮動ヘッドを採用し、IPX7の防水性能を備える。充電はUSB Type-Cで、フル充電までの時間は約1.5時間。1日1分の使用ペースなら、1回の充電で最大60日使えるとしている。

| 項目 | 内容 |
|---|---|
| 衆籌価格 | 105元(約15ドル) |
| 正規価格 | 149元(約22ドル) |
| 刃 | 3枚独立浮動、MIM製二重リング刃網 |
| 防水 | IPX7 |
| 充電 | USB Type-C、約1.5時間でフル充電 |
| 連続使用 | 1分/日で最大60日 |
| カラー | Twilight Blue、Rock Gray |

Gizmochinaによれば、S101雲紋刀頭版は約1か月前に発表された「Mijia Electric Shaver S100 Cloud Pattern Blade Edition」に近い刃の構成を、より低い価格で提供するモデルという位置づけだ。両モデルの仕様面での具体的な相違点は元記事に記載がなく、確認できていない。
