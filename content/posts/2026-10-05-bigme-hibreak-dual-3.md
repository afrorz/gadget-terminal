**Bigme HiBreak Dual 3** が公式ストアで予約を受け付けている。前面は6.13インチのE Ink、背面には5インチのLCDを磁石で取り付ける。LCDは外せるので、読書や手書きのときは薄いE Inkスマホとして、動画やSNSのときだけLCDを付けて使う、という作りだ。Bigmeは日本向けにもプレスリリースを出し、E Inkのリフレッシュレートは最大85fpsだとしている。

これはクラウドファンディングではなく、公式ストアの予約販売。ただし予約品なので、出荷は11月上旬から中旬の見込みという「予定」の段階にある。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 前面ディスプレイ | 6.13インチ E Ink（白黒300ppi／カラー150ppi）、最大85fps |
| 着脱式ディスプレイ | 5インチ LCD、1280×720px。E Ink面のみスタイラス対応 |
| SoC | MediaTek Dimensity 8300 |
| メモリ／ストレージ | 12GB+256GB／16GB+512GB。TFカードで最大2TB |
| 通信 | 5G／4G、Wi-Fi、Bluetooth 5.3 |
| バッテリー | 4,450mAh、30W急速充電 |
| カメラ | 背面50MP／前面5MP |
| OS | Android 16 |
| サイズ | 159.7×79.8×9.5mm（重量は公式ストアに記載なし） |

指紋認証は両方の画面にあり、それぞれ別の指でロック解除できる。PRによれば、前後カメラも画面ごとのロック解除に使える。

## 価格は組み合わせで8通り

公式ストアの価格は、容量、白黒かカラーか、LCDを付けるかで分かれる。掲載時点の価格は次のとおり。

| 構成 | LCDなし | LCD付き |
| --- | --- | --- |
| 12GB+256GB 白黒 | 569ドル | 629ドル |
| 12GB+256GB カラー | 589ドル | 649ドル |
| 16GB+512GB 白黒 | 689ドル | 749ドル |
| 16GB+512GB カラー | 709ドル | 769ドル |

LCDは後から買い足せると、PRにも書かれている。ストアの商品ページには649ドルに加えて、取り消し線つきの1,048ドル（38%オフ）が併記されている。

## 日本から見るとどうか

最大の論点は技適だ。HiBreak Dual 3は5GとWi-Fi、Bluetoothを積むスマートフォンで、日本で電波を出して使うには技術基準適合証明が前提になる。総務省の技適データベースを引いたかぎり、Dual 3に当たる型番は見つからなかった。ただし同じBigmeの別機種（HiBreak Plusなど）は2026年7月に認証が登録されており、Dual 3についても今後の登録はあり得る。現時点で「取得済み」とは言えない。個人輸入して国内の通信に使った場合、技適が無ければ電波法違反になる。

国内の販売については、PRはBigmeの日本公式Amazonストアのリンクを載せているが、Dual 3がそこで売られているかは確認できていない。日本語での検索でも、国内代理店やMakuakeの案内は見つからなかった。海外の公式ストアから買う場合、送料・関税・保証の扱いは購入前にストアで確認したい。

待つなら、国内正規品のE Inkスマホを先に試す手がある。BOOXのPalma 2はAmazon.co.jpで売られていて、技適の心配がない。Dual 3の売りは着脱LCDと85fpsなので、動画やアプリも1台でこなしたい人は、国内展開か技適の登録を待つのがよい。

なお、この記事の価格と在庫はすべて掲載時点のものである。この記事を書いた時点で、実機を使った詳細なレビューは確認できていない。
