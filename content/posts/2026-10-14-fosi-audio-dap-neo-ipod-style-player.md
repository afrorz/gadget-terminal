Fosi Audioの「DAP Neo」は、iPodの形を借りた音楽プレーヤーだ。2.4インチの画面の下に白いクリックホイールがあり、左側面にボタンが付く。ストリーミングサービスには対応せず、パソコンから入れた曲だけを再生する。公式ページの宣伝文句は「Stop Scrolling. Start Listening.」で、通知やSNSから離れて聴くための製品という位置づけだ。

## 仕様（公式ページ）

| 項目 | 内容 |
|---|---|
| DAC | CS43198 |
| 出力 | 3.5mmシングルエンド、129mW、SNR 127dB |
| 画面 | 2.4インチ TFT液晶、320×240 |
| 対応形式 | MP3、FLAC、WAV、APE、M4A、DSD |
| 無線 | Bluetooth（コーデックはSBCのみ） |
| 連続再生 | 最大12時間 |
| ストレージ | 16GBまたは64GB（カード付属）、microSDで最大256GB |
| 筐体 | 全金属、5軸CNC加工。背面は防指紋のAGガラス |
| サイズ・重さ | 97×47×10.6mm、75g以下 |
| 価格（米国、掲載時点） | 16GBが79.99ドル、64GBが119.99ドル |

4.4mmのバランス出力は付かない。Yanko Designも、バランス接続のイヤホンを使う人には向かないと指摘している。FiiOやSonyのような本格派と張り合う製品ではなく、小さくて安い「聴くだけの機械」を狙った作りだ。

## 日本から見るとどうか

日本向けの販売は、掲載時点で確認できていない。公式ストアは送料無料をうたうが、日本への発送条件は確認できていない。国内の楽天市場にはFosi Audioのストアがあるものの、DAP Neoは見つからなかった。

技適は番号まで確認できていない。Bluetoothを内蔵するため、日本で無線機能を使うなら技適が論点になる。総務省のデータベースでFosi Audioの登録は見つからなかった。有線のイヤホンだけで使うなら電波は出さない。

今日から買える代替品としては、国内正規品のHiBy R1がある。画面付きの小型プレーヤーで、LDACとハイレゾ再生に対応し、国内保証がつく。iPod風の操作感そのものが目的なら、DAP Neoの国内展開を待つことになる。実機のレビューはまだ見つかっておらず、ホイールの操作感や音質は評価待ちだ。
