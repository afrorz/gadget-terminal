Shureが、USBゲーミングマイク「MV6」の2代目となる「MV6 Gen 2」を発売した。価格は169ドル、159ポンド、150ユーロで、shure.comと正規販売店で買える。黒に加えて新色の白が用意され、白モデルにはマイクのフォームも色を合わせた起毛素材が使われる。いずれのモデルにも、デスクスタンドとUSB-Cケーブルが付く。

## Gen 2で変わったところ

Shureの発表では、マイク内部のDSPで処理する機能が、効きを調整できる形になった。

| 項目 | 内容 |
| --- | --- |
| 形式 | USB-C接続のゲーミング・配信向けマイク |
| オートレベルモード | 音量をならす強さと反応速度を選べる（ささやき声から叫び声まで一定に保つ） |
| リアルタイムデノイザー | スライダーで効き具合を調整（ファンやキーボード音、同居人の声など） |
| EQ | 5バンドのカスタムEQ。Dark／Natural／Brightの簡易設定も |
| ポップ対策 | デジタルポッパーストッパー内蔵 |
| プリセット | Speech／Singing／Instrumentの3種 |
| ケーブル | 2mのUSB-Cケーブル（付属） |
| スタンド | 防振ベース付きデスクスタンド、5/8インチネジでブームアームに取り付け可 |
| モニタリング | 3.5mmヘッドホン端子（遅延なし）、タップでミュートするボタンとLED |
| 対応機器 | PC、Mac、Android、iPhone・iPad（MFi認証） |
| 設定アプリ | MOTIVのデスクトップ・タブレット・モバイル版（無料）。設定はマイク本体に保存できる |
| 価格 | 169ドル／159ポンド／150ユーロ |

出典はShure公式ニュースルームとTechPowerUp。音質の評価や、初代との実測での違いは、実機レビューが出ていないため書けない。

## 設定をマイクに保存できる

MOTIVアプリで調整した内容は、マイク本体に保存される。PCを替えても、タブレットやスマートフォンにつないでも、同じ音で使える。

## 日本から見るとどうか

**初代MV6は国内で発売済みで、Gen 2の国内情報は確認できていない。** シュア・ジャパンは初代MV6を2024年9月27日に発売し、ASCII.jpは予想実売価格を2万7,500円前後と報じた。Gen 2について、シュア・ジャパンの発表や国内価格は、日本語での検索では見つからなかった。

**技適とPSEの問題は小さい。** USB-C接続の有線マイクで電波を出さないため、技適の対象外になる。海外から個人輸入しても、通信まわりの法的な不安は無い。ただし、保証と修理は国内の正規ルートに乗らないため、故障時はShureの海外窓口とのやりとりになる。

買うか待つかの目安は次のとおり。白い外観や5バンドEQ、2mのケーブルが目当てなら、国内発売を待つか、為替と送料を見て海外から取り寄せる。音量調整とノイズ低減が今すぐ要るなら、国内正規品の初代MV6が今日から使える。初代の機能は、同じオートレベル、ポップフィルター、デノイザーの系統だ。
