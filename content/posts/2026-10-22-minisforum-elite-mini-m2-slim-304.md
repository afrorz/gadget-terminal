Minisforumは、Intel Core 3 304を積むミニPC「Elite Mini M2 Slim-304」を公式ストアで売り出した。本体は112×112×37.15mmで重さ0.44kg。メモリとSSDが付いた構成で、8GB+256GB版が399ドルからだ。

## 構成と価格

公式ストアの価格は次のとおり（掲載時点、2026年10月22日）。

| 構成 | 価格（通常価格） | 出荷予定 |
|---|---|---|
| 8GB RAM + 256GB SSD | 399ドル（499ドル） | 11月中旬 |
| 12GB RAM + 256GB SSD | 423ドル（529ドル） | 11月上旬 |
| 16GB RAM + 512GB SSD | 503ドル（629ドル） | 11月上旬 |

価格はセール表示で、通常価格は括弧のとおり。

## 主な仕様

| 項目 | 内容 |
|---|---|
| CPU | Intel Core 3 304（5コア5スレッド） |
| 有線LAN | 2.5GbE × 2（Intel I226-V） |
| 無線 | Wi-Fi 6E（AX211）、Bluetooth 5.4 |
| メモリ | 最大64GB（DDR5） |
| ストレージ | M.2 2280 PCIe 4.0 x4 NVMe × 1（最大2TB） |
| 映像出力 | HDMI 2.0 × 2、USB4 × 1、USB-C × 1（いずれも4K@60Hzまで） |
| OS | Windows 11 |
| 騒音 | 負荷時28.1dB（50cm） |

## M2 Airとの関係

公式ストアのページでは、M2 Slim-304とM2 Air-304が並べて掲載されている。Notebookcheckは、M2 Slimは先に出たM2 Airと中身がほぼ同じで、違いは筐体だと伝える。公式の仕様表だけでは、筐体以外の差を確認できなかった。本サイトでは8月にM2 Air-304を取り上げており、そのときの仕様を知っていれば、新しい点は筐体の形と構成ごとの価格にとどまる。

## 日本で買える？使える？

国内の取り扱いは、掲載時点で確認できていない。買うなら公式ストアからの個人輸入になる。日本への発送可否や関税、保証の窓口は、購入手続きの画面で確認したい。

技適は確認できていない。総務省のデータベースで、Minisforum名義の登録を引けなかった。Wi-Fi 6EとBluetooth 5.4を内蔵するため、日本で無線を使うには技適の確認が要る。2.5GbEが2口あるので、有線LANだけで運用すれば無線の問題は避けられる。

国内の販売店で今すぐ同じ用途の機器を探すなら、デュアル2.5GbEを持つBeelink MINI-S13 Proが楽天市場で売られている。CPUはIntel N150で系統が違うが、ルーターやNAS代わりの用途なら候補になる。
