新興PC周辺機器ブランドのXERONが、Gamescom 2026（8月26〜30日、ドイツ・ケルン）で360mmオールインワン水冷CPUクーラー「NEX L360 ARGB」を披露した。XERONは2026年のComputexでデビューしたばかりのブランドで、Gamescomが欧州市場向けの初めての大型出展になる。ラジエーター一体型の完成品として、黒（NEX L360 ARGB BK）が74.99ドル、白（NEX L360 ARGB WH）が79.99ドルの推奨小売価格で用意される（2026年8月27日時点、TechPowerUp報道）。

## スペック

| 項目 | 内容 |
| --- | --- |
| ラジエーター | アルミ製、396×120×27mm、360mm対応 |
| チューブ長 | 400mm |
| 対応TDP | 最大300W |
| ポンプ | 3相6スロット、800〜2,500rpm、最大騒音30dB(A)、サイズ72.9×72.9×67mm |
| ファン | 120mm×3、800〜2,400rpm、最大75.39CFM、静圧2.71mmH2O、最大騒音34.9dB(A) |
| 対応ソケット | Intel LGA1851/1700/1200/115X、AMD AM5（オフセットブラケット付属）/AM4 |
| カラー | ブラック／ホワイト |
| 価格 | 74.99ドル（BK）／79.99ドル（WH） |

ポンプヘッドは全面ARGB発光で、標準の5V ARGBヘッダーに接続する。ロゴプレートは磁石で固定されており、90度回転させることでケースの縦置き・横置きどちらにも対応できる。ファンは羽根同士がつながった一体型ブレード構造で共振を抑え、フレームを中抜きしてARGB光を拡散させる設計。配線はデイジーチェーンでフレーム内を通し、ケーブルをまとめやすくしている。

## 日本から見るとどうか

**まず、無線機能を持たない部品なので技適は関係ない。** ARGB制御は有線のマザーボードヘッダー経由であり、電波法上の懸念はない。

**問題は国内の販売網がまだ無いことだ。** XERONはComputex 2026でデビューしたばかりの新興ブランドで、Gamescomの発表資料でも「欧州の販売代理店を募集中」と説明されており、アジア太平洋、ましてや日本向けの流通体制は現時点で確認できていない。個人輸入する場合は保証・サポートが実質無い状態での購入になる点に注意が必要だ。

**対応ソケットは国内の主要自作PC環境をほぼカバーする。** Intel LGA1851/1700/1200/115X、AMD AM5/AM4という組み合わせは、現行世代から一世代前のプラットフォームまで幅広く含む。価格自体は74.99〜79.99ドルとDeepCoolやCorsairなど既存ブランドの360mmARGBクーラーと大きく変わらない水準だが、送料や関税を考えると個人輸入では実質的にもう少し高くつく。

新興ブランドゆえの不確実性を避けたいなら、同クラスの360mm ARGBクーラーとしてDeepCool LS720が国内で正規に流通しており、保証・サポート面で安心して選べる。
