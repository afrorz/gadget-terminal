XGIMIがIFA 2026(会期9月4〜8日、ベルリン)で、超短焦点(UST)レーザーTV「AURA 3」シリーズを発表した。上位機「AURA 3 Max」と標準機「AURA 3 Pro」の2機種構成で、XGIMIは「世界初の4K・120Hz出力対応UST機」とうたう。正式発売はKickstarterを通じて2026年10月20日から、価格はAURA 3 Proが2,199ドルから、AURA 3 Maxが2,399ドルからとされる。現在は公式サイトで50ドルの返金可能なデポジットを受け付けており、支払うと追加で200ドル引きの権利などが得られるという。

## スペック(AURA 3 Max)

| 項目 | 内容 |
| --- | --- |
| 投影方式 | RGB三色レーザー+Dynamic Dual Iris(絞り機構)、公称ネイティブコントラスト8,000:1 |
| 明るさ・色域 | 最大5,700 ISOルーメン、BT.2020比110%カバー |
| 投影距離 | スロー比0.163:1。壁から約20cmで120インチ、最大200インチまで対応 |
| 対応リフレッシュレート | 4K/120Hz(DLPC8545を2基並列動作)、1080p/240Hzモードも搭載 |
| ゲーム機能 | HDMI 2.1、VRR・ALLM・AMD FreeSync Premium・Dolby Vision Gaming、入力遅延は最小1ms(公称) |
| HDR/映像 | Dolby Vision、HDR10+、HDR10、HLG、IMAX Enhanced、Filmmaker Mode、3D(専用メガネ2組付属) |
| OS | Google TV(Netflix・Prime Video・YouTube等にネイティブ対応)、Google Cast |
| 音響 | Harman Kardon製80Wスピーカー、Dolby Atmos・DTS Virtual:X |
| 価格(Kickstarter) | AURA 3 Pro 2,199ドルから/AURA 3 Max 2,399ドルから(いずれも掲載時点) |

本体が使われていない待機時には、壁紙やデジタルアートを映す「XGIMI WALL」というアンビエント表示機能も備える。なお中国国内では別ブランド展開で数か月先行して発売済みとされ、今回のKickstarter展開はグローバル版という位置づけになる。

## 「まだ製品ではない」ことに注意

現在受け付けているのはあくまで返金可能な50ドルのデポジットで、正式な製品購入ではない。Kickstarterでの本発売は10月20日を予定しているが、クラウドファンディング案件に共通する時期変更・仕様変更のリスクがある。ここで示した価格・仕様は掲載時点でXGIMIが公表している計画であり、確定した小売価格ではない。

## 日本から見るとどうか

**日本向けの発売時期・価格は未発表。** 掲載時点でXGIMIの予約ページは米国・英国・EU向けの公式ストアのみで案内されており、日本語での告知や日本向け価格は確認できなかった。Kickstarter経由で個人輸入する場合、Wi-Fi・Bluetoothを内蔵する本機には技適が別途必要になる点にも注意したい。

**価格はドル建て、かつハイエンド帯。** Kickstarter限定価格でも2,199ドルからと安価ではなく、為替次第で円換算額はさらに変動する。関税や送料もKickstarter経由の海外発送では別途かかることが多い。
