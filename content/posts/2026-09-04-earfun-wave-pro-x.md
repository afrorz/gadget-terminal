EarFunが2026年9月3日、ワイヤレスヘッドホン新製品「Wave Pro X」を129.99ドルで発売した。EarFun公式サイトとAmazonで即日発売されている。目玉は40mmと10mmのドライバーを1つの音響中心に揃えて配置する新設計「DCAA(Dual-Coaxial Acoustic Architecture)」と、Qualcommの新しいサウンド向けチップの採用だ。

## スペック

| 項目 | 内容 |
| --- | --- |
| 価格 | 129.99ドル(掲載時点、米国) |
| チップ | Qualcomm Snapdragon S3 Gen 1 Sound Platform(QCC3095)、Bluetooth 6.0 |
| ドライバー | DCAA方式、40mm DLC動的ドライバー+10mm LCPドライバーを同軸配置、AIクロスオーバー同期 |
| ノイズキャンセリング | Adaptive Hybrid ANC、8マイクのハイブリッド構成、USB/AUX有線接続でもANC有効 |
| 対応コーデック | Qualcomm aptX Adaptive、aptX Lossless、LDAC、Hi-Res Audio認証、ロスレスオーディオ対応 |
| バッテリー | 最大90時間(LE Audioの省電力性を活用) |
| その他 | Auracast、Google Fast Pair、マルチポイント接続、専用アプリでのゲーム向け低遅延モード |

EarFunによれば、DCAAは2つのドライバーを別々の経路で鳴らすのではなく、同一の音響中心から発音させることで低域から高域までの位相ズレを抑える設計だという。ANCは周囲の騒音環境をリアルタイムに解析し、電車内やオフィスのような騒がしい環境では強く、静かな環境では弱くかける「適応型」だとしている。

## 日本から見るとどうか

**国内発売の告知は掲載時点で確認できていない。** 公式サイトとAmazonでの発売が案内されているのみで、国内正規代理店の取り扱いやEarFun公式の日本向けページでの案内は見当たらなかった。技適の取得状況もWave Pro X単体では確認できていない。

**ただしEarFunは国内実績のあるブランドではある。** 前モデルの「EarFun Wave Pro」はVGP 2024 SUMMERを受賞し、国内の正規代理店(楽天市場のEarFun公式店)から購入できる。今回のWave Pro Xについても、今後同様に国内向け販売が始まる可能性はあるが、掲載時点では未確定として扱いたい。

**価格はドル建て。** 129.99ドルは為替により円換算額が変動し、Amazon.co.jpでの取り扱いが始まった場合も米国価格とは異なる可能性がある。

**今すぐ試したいなら。** 同じDCAA・Bluetooth 6.0搭載機ではないが、EarFunの適応型ANCを国内サポート付きで体験したい場合は、前モデルのWave Proが選択肢になる。
