Shift Roboticsが、足に固定する電動シューズ「Moonwalkers」の新型「Dusk」を発売した。これまでのモデルは靴に取り付けるサイズが1種類だったが、Duskは靴のサイズに合わせてS・M・Lの3サイズから選べる。価格は1,199ドルで、公式ストアの掲載時点では3サイズ・3色とも注文できる。ストアには「最初のロットは200足、出荷は10月12日に始まる」とある。

Moonwalkersは、カーネギーメロン大学発のスタートアップ Shift Robotics が作る、靴に付ける動力付きの車輪だ。歩く動きに合わせてモーターが回り、歩行を速くする。ローラースケートのように自分で蹴って滑る道具ではない。

## Duskで変わったところ

New Atlasの記事とShift Roboticsの公式ストアから、主な項目を整理する。

| 項目 | 内容 |
| --- | --- |
| 価格 | 1,199ドル（掲載時点） |
| 最高速度 | 7mph（11km/h） |
| 重量（1足あたり） | S 1.60kg／M 1.73kg／L 1.95kg |
| 対応サイズ | S: 米男性4〜6・女性5〜8、M: 米男性6〜9・女性8〜10、L: 米男性9〜13・女性10〜14 |
| 体重制限 | 100kgまで |
| 充電時間 | 約90分 |
| 防水 | IP54（水の飛まつ程度） |
| 色 | Cedar／Obsidian／Heliotrope |
| 保証 | 1年（公式ストア表記） |

歩き方の判定には、新しい歩行モデル「S.E.N.S.A.」が使われる。歩く・走る・跳ぶを見分け、坂の傾きに応じて補助の強さを変える、とNew Atlasは書いている。約10歩で歩幅を学習するという。10月下旬にはアプリが刷新され、速度の余力や左右の力の差など5つの指標で歩き方を分析する予定だ。

ハードウェア側では、足の曲がりに沿って動く関節構造、バッテリーセルの変更、モーターの通気口で、連続出力を従来の約2倍にするとしている。数値はいずれもメーカー側の説明で、第三者の実測値は確認できていない。

## 日本から見るとどうか

**買えるかどうかと、使えるかどうかは別の話になる。** 公式ストアの配送先一覧に日本は入っているが、日本向けの送料・関税・到着日数は、カートに進まないと分からず、本稿では確認できていない。

**技適は確認できていない。** 本体はスマートフォンのアプリと連携する。総務省の技適データベースを事業者名「Shift Robotics」で引いたところ、該当は0件だった。無線機能を持つ製品を国内で電波を出す状態で使えば、電波法上の問題になりうる。型番での照合までは行えていないので、使えると断定もできない。

**公道で使えるかも、公的な見解は確認できていない。** 動力で動く履物は、国内の道路交通の区分でどう扱われるか決まった判断が見当たらない。日本語の検索でも、国内で正式に販売する代理店は見つからなかった。

読者が取れる行動は次のとおり。1,199ドルは小さな買い物ではない。国内の正規代理店か、技適の取得が告知されるまで待つのが安全だ。それでも買うなら、使う場所は私有地やサーキットなど公道以外に限り、保証と修理は海外窓口とのやりとりになる前提で判断する。
