**Realme P4s Lite** は、Realmeがインドで発表した低価格スマートフォンだ。8月にインドで出たP4sの下位にあたる派生モデルで、スペックはP4sよりやや抑えられている。売りは7,000mAhのバッテリーで、Realmeは「最適なバッテリー状態を最大6年維持できる」としている。

## 仕様

| 項目 | 内容 |
| --- | --- |
| ディスプレイ | 6.75インチ LCD、1570×720（HD+）、120Hz |
| SoC | Unisoc T7250 |
| メモリ／ストレージ | 4GB LPDDR4X／64GBまたは128GB（UFS 2.2） |
| バッテリー | 7,000mAh。15W充電、15W USB PD対応 |
| カメラ | 背面13MP（オートフォーカス）、前面5MP |
| 通信 | 4G、Wi-Fi 5、Bluetooth 5.2、GPS |
| その他 | IP64、側面指紋センサー、3.5mmイヤホンジャック |
| 色 | Moonlight Silver、Nebula Black |

5Gではなく4Gの機種である。充電は15Wにとどまるので、7,000mAhを使い切った状態からの充電には時間がかかる。

## 価格と販売

| 構成 | 価格（インド） |
| --- | --- |
| 4GB+64GB | 16,499ルピー |
| 4GB+128GB | 18,499ルピー |

販売は10月8日0時（インド時間）から、Realmeの公式サイトとFlipkartで始まる。価格は掲載時点のもので、銀行オファーなどによる割引は別にある。
