GMKtecが、AMD Ryzen AI Max+ PRO 495と192GBのLPDDR5X-8533メモリを積んだミニPC「EVO-X5 Pro」を正式に発売した。公式ストアの価格は2TB SSD構成が6,599ドル、4TB構成が6,899ドル(掲載時点)。同社は、量子化した320B(3,200億)パラメータのLLMを、ネットワークにつながずに単体で動かせると説明している。**この性能は同社の発表値で、第三者の検証は確認できていない。**

## スペック

| 項目 | 内容 |
| --- | --- |
| CPU | Ryzen AI Max+ PRO 495(16コア/32スレッド、最大5.2GHz) |
| GPU | Radeon 8065S(40CU) |
| NPU | XDNA 2、55TOPS |
| メモリ | 192GB LPDDR5X-8533(ユニファイド) |
| ストレージ | M.2 2280 NVMe×3、最大24TB |
| 有線LAN・無線 | 10GbE×2、Wi-Fi 7 |
| 端子 | USB4 v2(80Gbps)×2、USB4(40Gbps)×2、USB 3.2 Gen 2×2、HDMI 2.1 |
| セキュリティ | dTPM 2.0、AMD DASH、指紋認証付き電源ボタン |
| サイズ/重量 | 221×80×195mm/約2.5kg、330W電源内蔵 |
| OS | Windows 11 Pro |
| 価格 | 2TB構成6,599ドル、4TB構成6,899ドル(掲載時点) |

同社の資料には、最大20台をラックに載せてクラスタとして使う構成も示されている。個人の机に置くというより、社内のローカルAI基盤やエッジ用途を狙った製品だ。

## 日本から見るとどうか

GMKtecは日本向けの公式ストア(jp.gmktec.com)を持ち、EVO-X5 Proの製品ページも掲載時点で公開されている。日本送料無料の表示があり、価格は期間限定の早割として円建てで100万円台の表示だった。掲載時点の表示であり、変動する。

一方、Wi-Fi 7を内蔵する製品でありながら、EVO-X5 Proの技適取得は公式の製品ページにも記載がなく、確認できていない。有線LANだけで使うなら電波法の問題は避けられるが、無線を使う場合は取得の確認を待つべきだ。価格が高額なため、保証や返品の条件も注文前に日本向けストアで確かめたい。

まずは同社の前世代EVO-X2をAmazon.co.jpで買い、ローカルLLMの使い勝手を確かめるのが現実的だ。情報源は同社の公式ページと海外メディアで、性能はいずれも同社の発表に基づく。
