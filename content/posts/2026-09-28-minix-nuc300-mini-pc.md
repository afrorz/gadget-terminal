香港のMinixが、Intel の省電力CPU「Core 3 N300」を積んだ入門向けミニPC「NUC300」を発表した。標準構成は16GB DDR5-4800メモリと512GB NVMe SSDで、価格は650ドル(掲載時点)。派手さのないスペックだが、2.5Gb EthernetとHDMI CECという、動画配信やリビング設置を意識した機能を積んでいるのが特徴だ。

## スペック

| 項目 | 内容 |
| --- | --- |
| CPU | Intel Core 3 N300(8コア8スレッド、最大3.8GHz) |
| メモリ | 16GB DDR5-4800MHz |
| ストレージ | 512GB M.2 2280 PCIe 3.0×4 NVMe SSD(増設用M.2スロットを別途搭載) |
| 映像出力 | HDMI 2.1×2、USB-C(DisplayPort 1.4)、トリプル4K@60Hz出力対応 |
| ネットワーク | 2.5Gb Ethernet、Wi-Fi 6、Bluetooth 5.2 |
| OS | Windows 11 Pro |
| 特徴 | HDMI CEC対応(テレビなど接続機器と電源連動) |
| 価格 | 650ドル(16GB/512GB構成、掲載時点) |

HDMI CECは、テレビなどのリモコン1つでNUC300本体の電源もオン・オフできる機能。リビングのメディアプレーヤー用途を想定した作りで、2.5Gb Ethernetも大容量ファイルのネットワーク経由再生を意識したものとみられる。一方でCPUのN300はAlder Lake-N世代の廉価モデルで、Notebookcheckは「性能に対して価格が魅力的とは言えない」と評している。

## 日本から見るとどうか

Minixは香港拠点のブランドで、Amazon.co.jpにも「MINIX NEO」ブランドの公式ストアを構えており、一部モデルは国内で正規に販売されている。ただしNUC300自体は掲載時点で米国のMinix公式ストア・Best Buy・Walmart・Amazon.comでの販売が確認できるのみで、日本のAmazon.co.jpや楽天市場での取り扱いは確認できていない。

技適についても、NUC300単体としての取得状況は掲載時点で確認できていない。Wi-Fi 6とBluetooth 5.2を内蔵するため、無線機能を国内で使うなら技適マークの有無を実機で確認したほうがよい。有線のEthernet接続のみで使う分には、技適の有無にかかわらず問題なく使用できる。

同じMinixブランド・同じN300世代のファンレスミニPC「NEO Z300-0dB」はAmazon.co.jpで既に販売されており、国内配送で購入できる。NUC300そのものの国内取り扱いを待たずに近い使い勝手を試したい場合の選択肢になる。

情報源はNotebookcheckとMinix公式サイトの2件。価格・スペックは掲載時点のものであり、為替や構成によって変動する。
