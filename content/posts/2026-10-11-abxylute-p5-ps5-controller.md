abxylute（アブサイルート）が、PS5向けのワイヤレスコントローラー「P5」を公式ストアで売り出した。公式ページの表示では、早期価格が75.99ドル、通常価格が89.99ドルで、早期価格は10月15日まで。出荷は10月末とされている。Notebookcheckは、DualSenseに着想を得た形で、アダプティブトリガーとホール効果スティックを載せて100ドル未満に収めたと伝えている。

## 仕様

公式ページに書かれている仕様は次のとおり。

| 項目 | 内容 |
| --- | --- |
| 対応機器 | PS5、PC、Android、iOS |
| 接続 | Bluetooth（PS5はドングル不要）、USB-C有線 |
| スティック | ホール効果方式 |
| トリガー | アダプティブトリガー（対応するPS5ゲームで抵抗が変わる） |
| 背面ボタン | 2つ、割り当て変更とマクロに対応 |
| 前面の機能ボタン | TURBO、ROCKER |
| バッテリー | 1,500mAh、約8時間（使い方による） |
| 重さ | 285g |

スマホ用コントローラーで知られる会社が、据え置き機向けに出した製品になる。公式ストアのメニューでは、同社のC系コントローラーやSwitch 2向けの製品と並んで掲載されている。
