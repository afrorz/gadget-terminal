OPPOは、フラッグシップのノイズキャンセリングイヤホン「Enco X4」を、Find X10シリーズとあわせて海外で展開する。中国では9月から売られていた。価格は英国が189ポンド、欧州が199ユーロで、欧州ではさらに20ユーロのクーポンが付くとGSMArenaが伝えている。

## 主な仕様

| 項目 | 内容 |
|---|---|
| ドライバー | 11mmウーファー＋6mmツイーター |
| 音の調整 | Dynaudio |
| 対応コーデック | AAC / SBC / LHDC / LC3 |
| Bluetooth | 6.1 |
| 防塵防水 | IP55 |
| 電池（ANCオフ・AAC） | 本体13時間 / ケース込み53時間 |
| 電池（ANCオン・AAC） | 本体6時間 / ケース込み26時間 |
| 電池（ANCオン・LHDC） | 本体5.5時間 / ケース込み22時間 |
| 色 | Glacier White / Aurora Violet |

53時間という数字はANCをオフにした場合のもので、ANCをオンにすると26時間に下がる。LHDCで聴くと、さらに短くなる。公式ページによれば、最大2.3Mbpsのロスレス伝送は、MediaTek製チップを積むOPPO Find X10シリーズとの組み合わせが条件になっている。ほかのスマホでは使えない機能がある点は、買う前に押さえたい。

GSMArenaの実機レビューでは、装着感が良く、操作が分かりやすく、複数回のフライトでノイズキャンセリングが効いたと評価されている。5時間のフライトのあと、電池は約半分残っていた。

## 日本で買える？使える？

OPPO Japanの公式サイトのイヤホン一覧には、掲載時点でEnco X4が載っていない。同じ一覧にはEnco Buds3 Proなどがあり、楽天市場のOPPO公式店でも売られているため、OPPOのイヤホンは国内で買えるブランドだ。ただしEnco X4の国内発売や価格の告知は、確認できていない。

技適は確認できていない。公式の型番ETEM2を総務省のデータベースで引いたが、該当は出なかった。Bluetooth 6.1を使う機器なので、海外版を輸入して使う場合は、技適が無い状態になる点を承知しておく必要がある。

読者が取れる行動は2つある。国内発売を待つか、いま国内で買える同じ価格帯のANCイヤホンを選ぶかだ。後者なら、ANCとワイヤレス充電に対応するAnker Soundcore Liberty 5が代替になる。なお、Enco X4はスマホとの組み合わせで機能が変わるため、OPPOのスマホを使っていない人ほど、ロスレス伝送などの一部機能が使えない点が効いてくる。
