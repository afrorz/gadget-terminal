Raven Resonanceは、メガネ型の端末「Raven Prism」の予約を始めた。ふつうのメガネに見える筐体に、ARM64のプロセッサーとLinuxベースのRaven OSを収め、スマホにつながなくても単体で動くのが特徴だ。価格は1,499ドル（度付きレンズ込み）で、予約金は返金可能な49ドル。出荷は2027年1月からとされている。本稿は、公式サイトと予約ページ、海外報道の内容を、掲載時点でまとめたもの。まだ製品ではなく、予約の段階だ。

## 主な仕様

| 項目 | 内容 |
|---|---|
| 表示 | 右目側に30度のフルカラー回折導波路ディスプレイ（LCoS光源）。視野の端に出る |
| 処理 | 4コア64ビットARM、RAM最大4GB、ストレージ32GB以上 |
| OS | Raven OS（Linuxベース）。SSHでログインでき、ARM64で動くものは動かせるとしている |
| 操作 | フレーム内の視線センサー。視線で選び、音声も使う。Bluetoothのキーボードやマウスも使える |
| カメラ | 13MP、水平視野84度。物理カバーを手で外さないと使えない。使用中は縁のライトが光る |
| 通信・センサー | 2.4/5GHzのWi-FiとBluetooth 5、マイク4基、スピーカー2基 |
| バッテリー | 磁石で着脱するRaven Wings。電源を落とさず交換でき、予備1組が付く |
| 度数 | 内蔵の度付きレンズで−4.5〜+4.5 |
| 価格 | 1,499ドル。予約金49ドル（掲載時点） |

## 気になる点

重量とバッテリー容量は公開されていない。予約ページでは、出荷は1月のバッチから夏にかけて複数に分かれ、初期のバッチは「満席」と表示されている。いま予約すると夏以降の出荷になる。この会社は製品を出荷した実績をまだ示しておらず、第三者による実機の評価も確認できていない。予約金は返金可能とされているが、納期や仕様が動く可能性は大きい。

## 日本で買える？使える？

予約ページが出荷先として挙げているのは米国で、欧州連合向けは近く対応するという。日本は挙がっていない。Wi-FiとBluetoothを内蔵するため、日本で使うには技適が要るが、取得は確認できていない。

日本向けが出るには、技適の取得と、国内向けの出荷または販売元が必要になる。待てる人は、公式サイトの案内を追うのが確実だ。今すぐ視界に画面を出したいなら、国内で買える表示用のARグラス（XREALなど）がある。こちらはLinuxを内蔵せず、PCやスマホにつないで映す前提の製品だ。
