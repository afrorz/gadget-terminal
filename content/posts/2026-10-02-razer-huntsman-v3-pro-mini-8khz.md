Razerが、60%サイズのゲーミングキーボード「Huntsman V3 Pro Mini 8KHz」を発表した。既存のHuntsman V3 Proシリーズに加わる、最も小さいサイズの8,000Hzモデルだ。Razer公式の米国ページでは179.99ドルから、日本の公式ページでは30,880円からと表示されている（いずれも掲載時点。構成によって価格が分かれる）。

## 仕様の要点

Razerの発表をもとに整理する。数値はいずれもメーカーの主張で、第三者の測定は確認できていない。

| 項目 | 内容 |
| --- | --- |
| スイッチ | Razer Analog Optical Switches Gen-2（アナログ光学式） |
| 作動点 | 0.1〜4.0mmで調整可能、ラピッドトリガー対応 |
| 耐久 | 1億回のキー入力 |
| ポーリングレート | 8,000Hz（遅延0.48msとRazerは説明） |
| 入力機能 | Snap Flex／Snap Tap／Dynamic Keystroke／Dual-Keypress Priority |
| 筐体 | 5052アルミ合金の天板、ダブルショットPBTキーキャップ |
| 設定 | 数字キー列から作動点とラピッドトリガー感度を調整。プロファイル6件を本体に保存。ブラウザで操作するSynapse Webにも対応 |
| 接続 | 有線（着脱式USB Type-Cケーブル） |
| サイズ | 60%配列。修飾キーを軽く押すと矢印キーとして動く |

RazerはスイッチがRazerの比較対象より約2.5倍正確だと説明しているが、比較条件の詳細は公開資料からは読み取れない。

## 日本から見るとどうか

**日本の公式サイトで、すでに製品ページが公開されている。** 掲載時点で在庫あり、価格は30,880円からだった。米国の179.99ドルとは別建てなので、為替でそのまま比べても意味はなく、国内で買うなら国内価格を基準にするのが分かりやすい。個人輸入に頼る理由は薄い。

**技適やPSEの心配は小さい。** 有線のキーボードで電波を出さないため、技適の対象外になる。国内の公式サイトで買えば、保証も国内窓口で受けられる。

**買う前に見ておきたい点。** 8,000Hzのポーリングを活かすには、USBポートとマウス側の対応が要る。手元のマウスが1,000Hzなら、キーボードだけ8,000Hzにしても効果の出る場面は限られる。60%は矢印キーとファンクションキーが無いので、修飾キーの二役にどれだけ慣れられるかも判断材料になる。実機レビューが出るまでは、打鍵感と反応速度の評価は書けない。
