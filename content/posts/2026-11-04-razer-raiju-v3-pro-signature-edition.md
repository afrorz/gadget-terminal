Razerが、PlayStation 5の公式ライセンスを受けたコントローラー「Raiju V3 Pro」に限定版を加えた。Signature Editionは、骨格をマグネシウム合金にして260gに収め、初回は通し番号の入った1,337台だけを作る。出典は発表資料で、第三者の実機評価はまだ確認できていない。

## 通常版からの違い

素材と見た目が中心だ。骨格はマグネシウム合金で、グリップはマットな黒のTPU。中央のタッチパッドはレーザーで刻印したガラスで、ロゴ入りの半透明に着色されている。上面と背面は多角形のオープン構造で、ナノコーティングが内部の見える部分を保護する。ボタンはダブルショットのPBTで、表示が消えにくいとされている。

性能の系統は通常のRaiju V3 Proと同じだ。左右対称のスティックに非接触のTMRセンサー、6つの多機能ボタン、クローグリップ用バンパー2つ、マウスクリック式の背面ボタン4つを備える。PCでは「HyperPolling Wireless」で最大2,000Hzのポーリングに対応する。設定はRazer SynapseかRazer PSのスマホアプリから行い、プロファイルを本体に保存できる。

付属品は、レザー調の携帯ケース、形の違うスティックキャップ（低めの凸面と高めの凹面）、交換用の背面ボタンカバー4つ、アルマイト仕上げの背面ボタン交換工具、HyperSpeed Wireless用ドングル、USB Type-A to Type-Cケーブル。

| 項目 | 内容（発表資料より） |
| --- | --- |
| 対応 | PlayStation 5（PC向けに最適化） |
| 重さ | 260g |
| 骨格 | マグネシウム合金 |
| スティック | 左右対称配置、TMRセンサー |
| 背面ボタン | マウスクリック式4つ（カバー交換式） |
| PCでのポーリング | 最大2,000Hz（HyperPolling Wireless） |
| 台数 | 初回1,337台（通し番号入り） |
| 価格・発売日 | 発表資料に記載なし |

## 日本で買える？使える？

Razerの日本サイトには、この製品のページがある。ただし日本での価格と発売日は、掲載時点の発表資料と公式ページから確認できていない。1,337台の限定のため、日本への割り当てがあるかも不明だ。

無線の2.4GHzドングルで使う機器なので、技適の確認が要る。総務省のデータベースでRaijuの型番の登録は特定できていない。国内の販売ページが出れば、国内正規品として技適が前提になる。

発売前に同じ系統の操作感を試したいなら、PS5純正のDualSense Edgeが国内で買える。背面ボタンやスティックの調整ができ、技適を気にせず使える。Signature Editionは素材と台数で選ぶ製品なので、価格が出てから比べるのがよい。
