ASUSが、Qualcomm Snapdragon X2 Eliteを搭載した超小型AI PC「ASUS Ascent QN10」を発表した。体積0.7リットル未満の筐体に、最大80TOPSのNPU(Qualcomm Hexagon)と18コアのQualcomm Oryon CPUを組み合わせ、Microsoft Copilot+ PCの要件を満たす。Notebookcheckによれば、米国での価格は16GBメモリ・512GBストレージ構成が1,349.99ドル、32GBメモリの上位構成が1,699ドル(いずれも掲載時点)で、米国では既に販売が始まっているという。

## スペック

| 項目 | 内容 |
| --- | --- |
| CPU | Snapdragon X2 Elite(X2E-88-100、18コア、3.4〜4.7GHz) |
| GPU | Qualcomm Adreno X2-90(前世代比2.3倍の性能とASUSは説明) |
| NPU | Qualcomm Hexagon、最大80TOPS |
| メモリ | 16GB LPDDR5X-8533 または 32GB LPDDR5X-9600 |
| ストレージ | 512GB PCIe 4.0 x4 SSD(上位構成は1TBの言及あり) |
| 本体サイズ | 体積0.7リットル未満(5リットル級デスクトップより86%小型とASUSは説明) |
| 無線 | WiFi 7、Bluetooth 6.0 |
| インターフェース | USB4/USB-C(40Gbps)×3、USB-A(10Gbps)×3、USB-A(2.0)×1、HDMI 2.1、2.5GbE LAN |
| 対応OS | Windows 11(Copilot+ PC要件を満たす) |
| 価格 | 1,349.99ドル(16GB/512GB)、1,699ドル(32GB上位構成、いずれも米国価格・掲載時点) |

構成は公式画像から確認できたポート数で、TechPowerUpの発表文とNotebookcheckの記事で数値が一致している。

## 手のひらサイズにAI処理能力を詰め込む設計

ASUSはAscent QN10を「世界初の80TOPS NPU搭載AIミニPC」と位置づける。Snapdragon X2 Eliteのハイブリッドアーキテクチャにより、ローカルでのAI推論と、クラウドLLM APIを組み合わせた「ハイブリッドAgentic AI」ワークフローに対応するとしている。開発者向けにはQualcomm AI Hubを通じて175以上の事前最適化済みAIモデルにアクセスでき、独自モデルの持ち込み(BYOM)やデータの持ち込み(BYOD)にも対応する。セキュリティ面ではfTPM 2.0とMicrosoft Pluton security processorを備え、エンタープライズ用途も意識した作りだ。

## 日本から見るとどうか

ASUS公式製品ページは掲載時点で米国向けの内容で、日本での発売や価格は告知されていない。ASUSは日本でもミニPCブランド(PNシリーズ等)を展開しているが、Ascent QN10がそのまま国内投入されるかは不明だ。

論点になるのは技適だ。Ascent QN10はWiFi 7とBluetooth 6.0の無線モジュールを内蔵しており、日本国内で無線機能を使うには技適取得が必須になる。掲載時点で技適取得の有無は確認できていない。ASUSのような大手メーカーは国内投入時に技適を取得することが多いが、現時点では米国発表のみで判断材料がない。

Snapdragon系のCopilot+ PCを「技適取得済み・今日から買える」形で試したいなら、同じQualcomm Snapdragon X Eliteを積むMicrosoft Surface Laptop(第7世代)が代替になる。フォームファクタはミニPCではなくノートPCだが、NPUを使ったオンデバイスAI処理という体験は共通する。

情報源はTechPowerUp(ASUSのプレスリリースを掲載)とNotebookcheckの2媒体で、価格情報はNotebookcheck側にのみ記載があった。実機レビューはまだ出ていない。
