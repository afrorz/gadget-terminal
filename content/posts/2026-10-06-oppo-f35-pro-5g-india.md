**Oppo F35 5G** と **F35 Pro 5G** は、Oppoがインドで発表したFシリーズの新作だ。2機種ともバッテリーは8,000mAh、充電は80W SuperVOOC。インドではOppo公式、Amazon、Flipkartで予約を受け付けている。

## 2機種の違い

| 項目 | F35 5G | F35 Pro 5G |
| --- | --- | --- |
| ディスプレイ | 6.57インチ AMOLED、FHD+、120Hz | 6.77インチ AMOLED、FHD+、144Hz |
| 最大輝度（HBM） | 1,400nits | 1,800nits |
| タッチサンプリング | 1,000Hz | 4,000Hz |
| SoC | MediaTek Dimensity 6360 Max | 確認できていない |
| ストレージ | UFS 2.2（128GB） | UFS 3.1 |
| 背面カメラ | 50MP＋2MPモノクロ | 50MP（光学式手ブレ補正）＋8MP超広角 |
| 前面カメラ | 50MP | 公式ページで確認できていない |
| バッテリー | 8,000mAh、80W | 8,000mAh、80W |
| 防水防塵 | IP69K | IP69K／IP69／IP68／IP66 |
| ベイパーチャンバー | 4,300mm² | 5,000mm² |
| 重量 | 205g | 210g |
| 色 | Wave Blue、Mist Pink、Titanium Grey | Sunrise Orange、Wave Blue、Twilight Brown |

F35 5Gのバッテリーは、本体の薄さが8.8mm、重さ205gという寸法で8,000mAhを収めている。Pro側にはデュアルビュー動画と、雨の中でも画面操作しやすくする機能、ワンタッチで水を弾き出す機能が載る。
