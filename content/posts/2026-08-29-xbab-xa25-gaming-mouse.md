XBAB Techは、ゲーミングマウスの愛好家がひとりで始めたブランドだと自己紹介している小規模メーカーである。その第一弾製品「XA25」は、重量25g、寸法117×63×36mmのフルサイズ有線マウスで、シェルの外形はLogicoolのG100sやG305に近い。無線用のバッテリーを積まず、1.9mm径のウルトラフレックスケーブルに置き換えることで軽さを稼いでいる。

## スペック

| 項目 | 内容 |
| --- | --- |
| 重量 | 25g |
| 寸法 | 117×63×36mm |
| 接続 | USB有線(ウルトラフレックスケーブル 1.9mm) |
| ポーリングレート | 8000Hz |
| センサー | PixArt PAW3950 |
| MCU | Nuvoton M483 |
| メインスイッチ | Kailh Sword GM X |
| ホイールエンコーダー | TTC Dustproof Gold |
| サイドボタン | Omron D2LS-21 |
| シェル製法 | Multi Jet Fusion(粉末焼結3Dプリント)、無塗装、Stone Gray |
| 価格 | 169ドルから |
| 予約開始 | 2026年9月22日午前9時(太平洋時間) |
| 初回生産数 | 500台(北米・欧州・日本向け) |

XBAB Techはレイテンシーを詰めるため、DPIダウンシフトやスムージングといった機能をファームウェア側で無効化し、社内テストでは3マイクロ秒というファームウェアオーバーヘッドを主張している。またシェル形状を試すための3DプリントデータをWebサイトで公開しており、購入前に実物大の模型を自分で出力して握り心地を確認できる。

## 日本から見るとどうか

**まだ発売ではなく予約受付の告知段階である。** 9月22日午前9時(太平洋時間、日本時間では9月22日深夜〜23日早朝にあたる)に予約が始まるという発表であり、実際に手元に届く時期は公表されていない。

**技適の心配はいらないが、購入経路は海外通販一択になる。** USB有線接続のみで無線機能を持たないため、技適の対象外である。一方でXBAB Techの配送地域には日本(JP)が明記されており、海外通販に抵抗がなければ購入自体は難しくない。ただし日本語のサポートページや保証窓口は用意されていないとみられ、初回生産500台という数量は北米・欧州とも取り合いになる。

**「軽さ」で今すぐ確実に手に入れたいなら、国内で流通する同クラスの製品が選択肢になる。** XA25は形状確認用の3Dモデルこそ公開されているが、実機を試し握りできる店舗はない。似た方向性の製品を今日から使いたい場合は、同じPixArt PAW3950系センサーを積み、Amazon.co.jpで購入できる製品を検討する余地がある。
