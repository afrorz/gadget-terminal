中国のRetroidが、5.5インチと4.2インチという解像度もサイズも異なる2枚の液晶を上下に開くクラムシェル型のAndroid携帯ゲーム機「Pocket Duo Lite」の出荷を2026年9月17日に始めた。価格は4GB RAM/64GBストレージ構成で149ドル、6GB/128GB構成で169ドルから(いずれも掲載時点)。上位モデル「Pocket Duo」の廉価版という位置づけになる。

## スペック

| 項目 | 内容 |
| --- | --- |
| CPU | Qualcomm Dragonwing QCS6125(Snapdragon 665相当) |
| GPU | Qualcomm Adreno 610 |
| メモリ/ストレージ | 4GB/64GB または 6GB/128GB(microSD対応) |
| 上画面 | 5.5インチ IPS、1920×1080、60Hz、500nit、sRGB125% |
| 下画面 | 4.2インチ IPS、1280×960、60Hz |
| バッテリー | 6,000mAh |
| OS | Android 15(Retroidカスタムランチャー) |
| サイズ/重量 | 158×95×23.2mm/372g |
| 価格 | 149ドル(4GB/64GB)〜169ドル(6GB/128GB、掲載時点) |

下画面はゲームによってはタッチパッドやサブ表示領域として使う設計で、レトロゲームのマップ表示やコントローラー操作の補助に使われる。CPUのQCS6125はSnapdragon 665相当と非力な部類だが、この価格帯では上下2画面という物理構成自体が特徴になっている。

## 日本から見るとどうか

Retroid公式ストア(goretroid.com)は海外発送に対応するが、国内では並行輸入専門店のGameGadgetが既に取り扱いを始めており、4GB/64GB構成を数量限定特価24,800円(通常価格34,800円)で販売している。ただしGameGadgetの商品ページは「海外並行輸入品、ベンチャー商品」であることを明記し、「保証・補償されません。一切キャンセルできません」と注意書きを添えている。

技適についても、公式・並行輸入いずれの販売ページにもPocket Duo Liteの技適取得を示す記載はなく、掲載時点で確認できていない。本体はWi-Fi 5とBluetooth 5.0を内蔵するため、これらの無線機能を国内で使う場合は電波法上のリスクが残る。オフラインでmicroSD内のゲームを遊ぶだけであれば、無線機能を使わずに済む。

情報源はGeeky Gadgets、Retro Handhelds、GameGadget、デイリーガジェットの4件。価格・在庫状況はいずれも掲載時点のもので、並行輸入店の特価は変動・終了する可能性がある。
