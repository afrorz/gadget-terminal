Epomakerが、Alice配列をベースにした40%サイズの有線・無線キーボード「Alice40」を公式ストアで発売した。価格は69.99ドル（2026年11月12日時点）。キーは46個で、左右に分けた配列の中央にノブがある。

## 縦にずらす「Alice」

Alice配列は、左右の手に合わせて八の字に開いた配列で、通常のキーボードに近い感覚で使えるため、エルゴノミクスキーボードの入門として勧められることが多い。Alice40はこれに「縦列スタガー」を足した。行を横にずらす一般的な配列と違い、列を縦にずらして指の長さと動きに合わせる。TechPowerUpは、同じ価格帯のキーボードに無い特徴と見ている。

46キーには矢印キーと、左右に割れたスペースバーが含まれる。小型の分割キーボードでよく必要になる、ホームロウ・モッドやレイヤー切り替えに頼らずに使える構成だ。

## 主な仕様

| 項目 | 内容 |
|---|---|
| キー数 | 46（40%、縦列スタガー） |
| 構造 | ガスケットマウント、ホットスワップ対応。ケースはプラスチック製、内部に吸音材 |
| スイッチ | 標準はCreamy Jade（プリルブ済みのリニア。総ストローク3.6mm、押下圧45〜50gf） |
| キーキャップ | Cherryプロファイル、昇華印刷PBT。日没をイメージした配色 |
| 接続 | Bluetooth 5.0 / 2.4GHz / USB-C。2.4GHzとUSB-Cはポーリング最大1kHz |
| 遅延（公称） | 2.4GHzで5ms、USB-Cで3ms |
| 電池 | 3,000mAh |
| 重さ | 531g |
| その他 | 中央にノブ、角度調整できるフリップアウト脚（5〜8.5度）、2.4GHz受信機の収納スロット、バックライトはキー下側から照らす |
| ソフト | VIAと、Epomakerのオンラインドライバー「Hub」でキー割り当てを変えられる |

重さ531gと受信機の収納スロットから、持ち歩く使い方を想定している。プラスチックのケースなので、金属ケースの上位機とは質感が違う。

## 日本で買える？使える？

公式ストアは「Worldwide Shipping」をうたっていて、日本から注文できる見込みだ。日本向けの送料・関税・納期は確認できておらず、国内の販売元も見つかっていない。日本語の紹介記事も、こちらの検索では見つからなかった。

技適については、総務省のデータベースにShenzhen ChangYun Technologyの一括登録（217-263454、2026年8月4日）があり、型式欄にAlice40が入っている。Bluetoothと2.4GHzを国内で使う法的な根拠はここにある。ただし、届いた実機に技適マークが付くかは確認できていない。購入後に、本体か箱の表示を見ておきたい。

配列にも注意が要る。公式ページの画像は英語配列（ANSI）で、日本語配列は選べない。日本語の入力切り替えは、IMEの設定で行うことになる。

今すぐAlice配列を使いたいなら、国内で買えるKeychronのK11 Max（65%・無線対応）がある。Alice40のような40%サイズと縦列スタガー、ノブの組み合わせで国内に出ているものは、確認できていない。
