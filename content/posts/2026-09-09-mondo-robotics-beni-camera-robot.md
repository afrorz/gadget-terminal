Mondo Roboticsが開発した「Beni」は、飼い主について歩く犬のように持ち主を自動追尾し、4K映像を撮影する四輪の小型ロボットだ。2026年7月8日にKickstarterで募集を始め、9月6日に目標額5万ドルの約93倍にあたる467万1752ドル、支援者7420人を集めて募集期間を終えた。

## スペック

| 項目 | 内容 |
|---|---|
| カメラ | 4K/30fps・3K/60fps・1080p/100fps |
| 最高速度 | 時速28.8km（17.9マイル） |
| 最大ジャンプ高 | 25.4cm（10インチ） |
| 重量 | 1.75kg（3.86ポンド） |
| サイズ（長×幅×高） | 21.6×18.0×18.0cm |
| バッテリー | 交換式、1本あたり1.5時間。2回交換で4.5時間以上 |
| ストレージ | 内蔵32GB＋microSDスロット |
| 操作方法 | スマートフォンアプリ、腕時計型リモコン、ゲームパッド |
| 早期価格／正規価格 | 499ドル（終了）／799ドル |

障害物回避には本体側面の150度カメラを使い、左右から迫る障害物を検知するという。前面には目のような発光部があり、音と表情で状態を伝える機能も備える。

## 開発元はテスラのロボット開発出身者が共同創業

Mondo Roboticsは、深圳とパロアルトに拠点を置く200人以上のチームで構成される。公式サイトによれば、開発は2025年4月のコンセプト立案に始まり、同年7月に動作プロトコル完成、10月に外装デザイン確定、2026年3月には自己復帰機能（転倒時に自力で起き上がる機能）を確認、5月から30人以上のベータユーザーへの先行配布を経てKickstarterでの募集にこぎ着けた。PetaPixelによれば、共同創業者の1人Shuo Yang氏は博士号を持ち、テスラの人型ロボット「Optimus」の開発チーム出身だという。

## 日本から見るとどうか

Beniはスマートフォンアプリや専用の腕時計型リモコンで操作する仕様になっており、何らかの無線通信を利用しているとみられる。しかし、公式サイト・Kickstarterページのいずれを確認しても、Wi-FiやBluetoothの具体的な規格、技適の取得状況についての記載は見当たらなかった。技適マークのない無線機器を国内で電波を出して使うのは電波法違反にあたるため、この点が確認できないまま日本に持ち込んでも、電源を入れて無線機能を使うことは推奨できない。

日本国内での正規販売や代理店についての告知も、掲載時点では確認できていない。Kickstarterの募集は終了しているが、レイトプレッジでの支援は引き続き可能になっている。出荷予定は2026年10月1日とされているが、これはあくまで現時点の計画であり、クラウドファンディングである以上、遅延や仕様変更のリスクが残る。
