米ネバダ州リノの作り手Brennan Jordan氏が、5.3インチのAndroidスマホ「Enough Phone」をKickstarterで募集している。2026年11月5日7時50分時点（日本時間）で、支援額は97,710ドル、支援者は244人。目標額250,000ドルの約39%にあたる。募集は11月5日に始まり、締切は米国時間12月4日（日本時間12月5日午前3時）。

**これはクラウドファンディングの募集で、製品の購入ではない。** 公式サイトの画像は量産前のレンダリングで、仕様も「目標仕様」と書かれている。金額と支援者数は取得時点の値で、日々動く。

## どんなスマホか

公式サイトの目標仕様と、9to5Googleの報道を合わせると次のとおり。

| 項目 | 内容 |
|---|---|
| 大きさ | 約133×64×12mm未満（公式）。9to5GoogleはiPhone 13 miniと同程度で、より厚いと伝える |
| 画面 | 5.3インチ LCD、1520×720（9to5Google） |
| SoC | MediaTek Dimensity 7500（2.4GHz） |
| メモリ・保存 | 8GB RAM、128GB。microSDで拡張できる |
| カメラ | 背面 Sony IMX766の50MP、前面32MP |
| 電池 | 3,500mAh。背面のネジを外して交換できる |
| 通信 | 5G、Wi-Fi 6、GPS、Bluetooth、NFC |
| SIM | eSIM＋物理SIM1枚 |
| 認証 | 電源ボタンの指紋センサーと顔認証 |
| OS | Android 17。ソフトウェアの更新は2032年までとされる |

本体の背面は、再生PCの素材を使った艶なし仕上げと説明されている。OSはAndroid標準のほか、SLEKEが開発した最小限の画面構成の「OdysseyOS」を選べる。

## 何が面白いのか

大きな画面のスマホが当たり前になり、5インチ台のAndroidはほぼ無くなった。そこに、CPUもカメラも中級機の水準を載せて小さくまとめるのが狙いだ。電池が替えられるので、電池の劣化で端末ごと買い替える必要が減る。

不安もある。画面解像度は1520×720と高くなく、IPS液晶である。「mostly final（ほぼ確定）」とされる仕様でも、量産までに変わりうる。公式の予定表は、金型が11月に進行中で、試作機の完成が12月、量産開始が2027年4月、出荷開始が2027年5月。メモリ価格の高騰が納期に影響しうる、とも書かれている。作り手が過去にスマホを量産した実績は、確認できた資料に見当たらない。

## 価格と注意点

- **価格：** 9to5Googleによると、予定小売価格は599ドル。Kickstarterの早期枠は399ドル・449ドル・499ドル（掲載時点）。Kickstarterページ本体の内訳は、ランナー側で取得できなかったため未確認
- **注意：** 目標額250,000ドルに届かなければ、製品化されない
- **注意：** 日本の周波数帯（5Gのバンドなど）への対応は、公式には書かれていない

## 日本で買える？使える？

**掲載時点で、日本向けの発売や国内の販売元は確認できていない。** 日本語で「Enough Phone」を国内発売やMakuakeと合わせて検索した範囲では、国内の発表は見つからなかった。

- **入手：** Kickstarterで支援する形になる。日本に発送されるか、送料や関税がいくらかは、プロジェクトページの配送先で確かめる必要がある
- **技適：** 型番が未公表で、総務省のデータベースでは確認できていない。5G・Wi-Fi・Bluetoothを積むため、国内でこれらを使うには技適の取得が要る。日本向けの版が出るには、技適と国内の販売元が必要になる
- **対応周波数：** 日本の5Gや4Gのバンドに対応するかは、公式に明記されていない。日本の回線で使えるかは、ここで決まる
- **日本語：** AndroidのOSなので日本語は使えるとみられるが、OdysseyOSの日本語対応は確認できていない
