ASUSの「Ascent QN10」は、Qualcommの18コアCPU「Snapdragon X2 Elite」を載せたミニPCだ。6月のComputexで発表され、9月18日に米国での発売が報じられた。米国価格は16GB/512GB版が1,349ドル、32GB/512GB版が1,699ドル（いずれも掲載時点、後者は報道による）。OSはWindows 11 Pro（Arm版）で、Copilot+ PCに分類される。

## 仕様

| 項目 | 内容 |
| --- | --- |
| SoC | Snapdragon X2 Elite（X2E-88-100）、18コア |
| NPU | Hexagon、80TOPS（INT8） |
| GPU | Adreno X2-90 |
| メモリ | LPDDR5x、16GBまたは32GB（増設不可） |
| ストレージ | M.2 2280 PCIe Gen4 x4 NVMe SSDを2基。512GBと1TBに対応 |
| 前面 | USB4を2基、USB 3.2 Type-A（10Gbps）、USB 2.0 Type-A、音声端子 |
| 背面 | USB4、USB 3.2 Type-A（10Gbps）を2基、HDMI 2.1、2.5GbE、DC入力 |
| 無線 | Wi-Fi 7、Bluetooth 6.0 |
| 大きさ | 130×130×40mm、0.7L未満 |
| 電源 | 180W ACアダプター |

最大4台の4Kディスプレイに同時出力でき、重さはデータシートで620gとされる。一部の報道は別の重さを挙げていて、販売品での確認は取れていない。

## 海外レビューの評価

StorageReviewはSnapdragon X2 Eliteを載せた最初のミニPCとして試し、x86のミニPCを上回る結果としている。Geekbenchはシングル3,272、マルチ24,049で、Core Ultra 7 165Hより43〜73%高いという。Cinebench 2026はシングル639、マルチ6,476。3DMark Solar Bayは21,561。ファンはアイドル時に止まり、最大でも53dBAに収まった。

不満も明確だ。メモリは基板に載っていて最大32GBで、後から足せない。512GB版はGen5スロットが空いたままで、Windows on Armの互換性はアプリごとに確かめる必要がある。数値はいずれも同誌の測定で、当サイトでは再現していない。

## 日本から見るとどうか

掲載時点で、日本の発売日と価格は確認できていない。国内メディアは6月の発表時点で報じているが、国内の販売情報は見つからなかった。国内で買えると書けるのは、国内の販売ページが出てからだ。

技適も確認できていない。総務省のデータベースを型式「QN10」で引くと、別メーカーの「QN10-SE」が1件出るだけで、本機とは別物だ。Wi-Fi 7とBluetoothを内蔵するため、海外版を個人輸入して無線を使うのは電波法の問題になる。有線LANだけで使う手もあるが、その場合も保証は国内で受けられない前提で考えたい。

用途が「静かな小型のArmデスクトップ」なら、国内で正規に買えるMac miniが選べる。ただしOSはmacOSで、Windowsのソフトを動かしたい人の代わりにはならない。Windowsで使いたいなら、ASUS JAPANの国内発売の告知を待つのがいちばん確実だ。
