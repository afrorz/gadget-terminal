Googleが2026年9月21日、新しいラップトップ規格「Googlebook」を発表した。Android スマートフォンとの連携を軸にした設計で、通知やクイック設定はPixelと同じインターフェースを採用する。初弾モデルはAcer・ASUS・Dell・HP・Lenovoの5社から計5機種が出そろい、価格は899ドルから。発売は米国が2026年10月4日、英国・アイルランド・フランス・ドイツ・オーストラリアが10月5日で、この6か国以外への展開は掲載時点で発表されていない。

Googlebookの核はChromeOSとAndroidの統合にある。ChromeOSが培ってきたマルチウィンドウ操作やブラウザ性能と、Androidのネイティブアプリスタックを1つのOSにまとめた設計で、既存のChromebookとは別のライン、Windowsノートとも別のラインという位置づけになる。

## 対応モデルと価格

| メーカー・モデル | 価格(掲載時点) | プロセッサ |
| --- | --- | --- |
| Acer Googlebook 14 | 899ドル〜 | Intel Core Ultra 5/7(Panther Lake) |
| Dell XPS Googlebook | 1,199ドル〜 | Snapdragon X Elite |
| ASUS Googlebook 14 | 1,299ドル〜 | Intel Core Ultra 5/7(Panther Lake) |
| HP Googlebook 14 | 1,299ドル〜 | Snapdragon X Elite |
| Lenovo Googlebook 15 | 1,299ドル〜 | Intel Core Ultra 5/7(Panther Lake) |

## 共通スペック

| 項目 | 内容 |
| --- | --- |
| RAM | 16GB以上(32GBオプションあり) |
| ストレージ | 256GB以上のSSD |
| ディスプレイ | 最大2.8K、LCD/OLEDタッチスクリーン |
| バッテリー | 14時間以上 |
| NPU | 40+ TOPS |
| AI機能 | Magic Pointer(ジェスチャーで起動)、Rambler(音声で下書き)、Create My Widget(説明文からウィジェット生成) |

CPUは搭載モデルによってIntel Core Ultra系とSnapdragon X Elite系に分かれるが、RAM・ストレージ・NPU性能の最低ラインはGoogleが5社共通の基準として揃えている。

## 日本から見るとどうか

**掲載時点で日本は発売対象に入っていない。** 確認できているのは米国・英国・アイルランド・フランス・ドイツ・オーストラリアの6か国のみで、9to5GoogleとAndroid Authorityのいずれの記事にも日本展開への言及は無い。

技術面では、Wi-Fi・Bluetoothを積む通常のノートPCであり、日本で正規に販売されれば技適の取得自体は障壁にならない機種のはずだ。問題は販売網で、掲載時点では並行輸入か個人輸入以外に入手経路が無く、キーボードの日本語配列対応やGoogleのサポート窓口が日本語に対応するかも未確認となる。ChromeOSとAndroidを統合するという設計思想自体は、GoogleがPixelで進めてきたエコシステム連携の延長にあり、日本語入力やIME周りの作り込みがどこまで進んでいるかも実機を見るまで分からない。

価格帯はASUS・HP・Lenovoの1,299ドルからという設定を見る限り、既存のCopilot+ PCやハイエンドChromebookと競合する位置にある。今すぐ試したい場合の選択肢は、現状では海外発送に対応する米国内の直販サイトを個人輸入で使う以外にない。
