New Matterが、音楽の再生だけに絞った携帯プレーヤー「Sudo SP-01」を発表した。物理のタッチホイールを本体下部に置き、上に2.73インチ・320×320のタッチ画面を載せる。公式ページの予定価格は249ドル（税・送料別）。50ドルの予約金で最初の生産ロットの枠を押さえられる。出荷は2027年第4四半期の初めを予定している。

## まだ製品ではない

**現時点で買えるものではなく、予約の段階だ。** 予約金は返金可能で、購入時に代金へ充当されると公式ページにある。ただし価格は「予定」で、最終価格は購入手続きの前に確定すると書かれている。公式ページの画像は、実機の写真というより製品イメージに見える。出荷まで約1年あり、仕様や価格が変わる余地は大きい。

## 公式ページの仕様

| 項目 | 内容 |
| --- | --- |
| 再生 | オフライン再生とストリーミング |
| ストレージ | 64GB＋microSD最大1TB |
| 操作 | 物理のタッチホイール |
| 音声出力 | 3.5mmジャック＋Bluetooth |
| 画面 | 2.73インチ LCD・320×320・タッチ対応 |
| OS | Sudo OS |
| 寸法 | 103.5×58.6×8.5mm |
| 電池 | 20時間以上（メーカー表記） |
| 充電 | USB-C |
| 予定価格 | 249ドル（税・送料別） |

電池時間は、条件が書かれていないメーカー表記の値だ。通知を出さず、一覧から選んで再生するだけのUIで、再生画面に「LOSSLESS」と出る。どのストリーミングサービスに対応するか、どの音声形式を再生できるかは、公式ページには書かれていない。

Yanko Designは、ホイールの上にタッチ画面を重ねた構成を「どちらの時代に属するか迷っている」と評している。同誌が見たのも製品イメージで、実機のレビューではない。

## 日本から見るとどうか

**予約できる地域に日本は入っていない。** 公式ページの対象は米国・カナダ・英国・オーストラリア・ニュージーランドで、それ以外の国にはウェイトリスト登録が用意されている。日本語で検索して見つかったのは個人のレビュー記事までで、国内の取扱店や代理店の告知は確認できていない。

**技適は確認できていない。** 本機はWi-FiとBluetoothを備える。総務省の技適データベースを事業者名「New Matter」で引くと該当は0件だった。型式での照合は、型番が確定していないため行えていない。国内で電波を出して使うなら、技適の取得が前提になる。

出荷まで1年あるので、急いで動く必要はない。国内で使えるかは、発売が近づいた時点で技適の取得状況と日本向けの出荷の有無を確認して決めればよい。予約金は返金可能だが、予約の対象は5か国で、日本は掲載時点で含まれない。対象外の国向けにはウェイトリスト登録が用意されている。
