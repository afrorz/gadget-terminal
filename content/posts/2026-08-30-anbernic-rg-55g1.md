中国ANBERNICが、同社として初めてQualcomm Snapdragonプロセッサを採用したAndroidハンドヘルド「RG 55G1」を発表した。筐体デザインは任天堂のSwitch Liteに酷似しており、横長のボディに左右分割型のコントローラーを配置する構成も同じだ。発売日は8月31日で、価格は4GB+64GB構成が149.99ドル、8GB+128GB構成が174.99ドル。発売から3日間は4GB+64GB構成が139.99ドルに値引きされる。

## スペック

| 項目 | 内容 |
| --- | --- |
| OS | Android 14 |
| プロセッサ | Qualcomm Snapdragon G1 Gen 2(SG4250P、ANBERNIC初のSnapdragon搭載機) |
| メモリ/ストレージ | 4GB+64GB、または8GB+128GB(microSDで最大2TBまで拡張可能) |
| ディスプレイ | 5.5インチ Incell IPS、1920×1080 |
| バッテリー | 6000mAh、駆動時間約8時間、5V/9V-18W急速充電 |
| 寸法 | 幅208mm×高さ86mm×厚さ17mm |
| 特徴 | 6軸ジャイロセンサー、ファン+ヒートパイプによるアクティブ冷却、ホール効果トリガー・スティック、RGBスティックリング |
| カラー | Black、Retro Gray、Indigo |
| 価格 | 4GB+64GB 149.99ドル(発売3日間は139.99ドル)、8GB+128GB 174.99ドル |
| 発売日 | 2026年8月31日 |

これまでANBERNICのハンドヘルドはUnisocやRockchip系のプロセッサが中心だったが、RG 55G1で初めてQualcomm Snapdragonを採用した。ホール効果を使ったトリガーとアナログスティックに加え、6軸ジャイロセンサーやアクティブ冷却ファンなど、同社の従来機より一段上の機能を積む。

## 日本から見るとどうか

**まだ国内での正規販売は発表されていない。** 発売日が8月31日と迫っているものの、掲載時点でANBERNIC公式サイトからの海外発送が前提であり、国内代理店の取り扱いは確認できていない。

**技適とWi-Fi/Bluetooth。** 海外発送のAndroidハンドヘルドを国内で無線機能付きで使うには、技適の取得が前提になる。ANBERNICの過去モデル(RG556やRG557など)はAmazon.co.jpでも販売されているため、RG 55G1についても今後同様のルートで入手できる可能性はあるが、現時点で確約はない。価格はドル建てで、円換算額は為替により変動する。

**代替としてのANBERNIC RG557。** 同じANBERNICのAndroidハンドヘルドで、横長のSwitch型ボディを持つRG557はAmazon.co.jpから購入できる。Snapdragon搭載機ではないが、同ブランドの操作感を今日から確かめたい場合の選択肢になる。
