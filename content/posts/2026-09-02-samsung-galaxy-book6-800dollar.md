Samsungが、Galaxy Book6シリーズに新たなエントリーモデル「Galaxy Book6」を追加した。14インチ・Intel Core 3またはCore 5 315搭載で、米国価格は800ドルから。10月5日に米国で発売される。CES 2026で発表済みのGalaxy Book6 Pro/Ultraとは別に用意された、より手頃な価格帯の構成だ。

## スペック

| 項目 | 内容 |
| --- | --- |
| ディスプレイ | 14インチ16:10 LCD、1,920×1,200、350nit、アンチグレアコーティング |
| プロセッサ | Intel Core 3 または Core 5 315(地域によりCore 3の提供有無が異なる) |
| メモリ/ストレージ | 基本8GB+256GB、16GB RAM・512GB・1TBへのアップグレード可 |
| バッテリー | 61.2Wh、最大25時間駆動、45W充電(30分で33%) |
| ポート | USB-A×1、USB-C×2、HDMI 1.4×1、3.5mmジャック×1 |
| 通信 | Wi-Fi 6E(2×2)、Bluetooth 5.4 |
| 本体 | 厚さ15.7mm、重量1.35kg |
| その他 | Webカメラ2MP、ステレオスピーカー2×2W(Dolby Atmos)、デュアルマイク、キーボードはバックライト非搭載 |
| カラー | グレー、バイオレットシルバー |
| 価格(米国) | 800ドルから(2026年10月5日発売) |

価格は地域ごとに通貨が異なる。米国800ドル、イギリス800ポンドに対し、ヨーロッパは構成により850〜1,200ユーロ(ベルギーの例では8GB+256GBが850ユーロ、8GB+512GBが1,000ユーロ、16GB+512GBが1,200ユーロ)、カナダは1,200カナダドルで発売時期は未定。いずれも掲載時点の値で、為替換算した円表記はしていない。

## 日本から見るとどうか

日本ではGalaxy Book6 Pro/UltraがCES 2026の発表に合わせて既に案内されているが、今回の無印「Galaxy Book6」がsamsung.com/jpに載っている情報は確認できていない。価格を抑えたエントリーモデルという性格上、まずは米国・欧州向けの展開を優先している可能性がある。

Wi-Fi 6EとBluetooth 5.4を搭載する以上、国内で使うには技適が前提になるが、掲載時点でその取得状況についての案内はない。国内投入が発表されるまでは、価格や発売日を確定情報として扱わないほうがよい。

同価格帯で技適取得済みの国内正規品が欲しい場合は、samsung.com/jpで既に販売中のGalaxy Book6 Pro/Ultraか、他社の国内正規Windowsノートを検討するほうが確実だ。楽天市場のSamsung公式ストアではタブレットやスマートウォッチの取り扱いはあるが、掲載時点でGalaxy Book系列のノートパソコンの出品は確認できておらず、無理に代替品を挙げることはしない。
