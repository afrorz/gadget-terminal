Crealityの「K3」は、ノズルそのものを4本積み、印刷の途中で入れ替えるCoreXY方式の3Dプリンターだ。公式FAQによれば、ノズルの切り替えは1回4.8秒、色や素材の切り替えは15秒。予約受付は10月中旬に始まり、価格は900ドル未満になる見込みとしている。Notebookcheckは、中国で予約販売が始まったと報じている。

## 4本のノズルで何が変わるか

多色印刷は、色を替えるたびにノズル内の樹脂を押し出して捨てる方式が多い。K3は、色ごとに専用のノズルを持たせ、使うノズルだけを入れ替える。公式FAQが挙げる主な仕様は次のとおり。

| 項目 | 内容 |
| --- | --- |
| 方式 | CoreXY、ノズル交換式の多色印刷 |
| ノズル | 0.4mmの真鍮先端ノズルを4本同梱 |
| 切り替え時間 | ノズル4.8秒、色・素材15秒 |
| 耐久試験 | ノズル交換80万回以上 |
| 精度 | XYZ軸のずれ25μm未満 |
| 対応素材 | PLA、PETG、TPUを1回の印刷に混在可。TPUは95Aまで標準対応 |
| 給材 | 4本のスプールを内蔵、自動のロード・アンロード |
| ファームウェア | Klipperベース、段階的に公開。ルート権限あり |
| ソフト | Creality Print 7.0以降、OrcaSlicerと互換 |

オプションとして、複数の色を増やすCFS Hubがあり、0.2・0.4・0.6・0.8mmのノズル径を混ぜて使うキットも発売後に別売りされる。造形サイズと印刷速度は、公式FAQには書かれていない。

## 価格と時期

公式FAQは「900ドル未満での発売を見込む」とし、正式な価格とバンドルは未確定としている。予約の開始は10月中旬で、出荷時期は書かれていない。FAQのページに表示されている地域は米国（英語）のみだった。公式の価格が出るまでは、900ドルは上限の目安にとどまる。

## 日本から見るとどうか

**国内での扱い。** Crealityは日本語の公式サイトを持ち、ノズル交換式プリンターの案内ページも置いている。ただ、K3そのものの国内価格・発売日・販売店は、掲載時点で見つからなかった。「K3 国内 発売」で検索しても、日本語の確認できる発表は出てこなかった。

**技適。** 公式FAQは、Wi-Fiなど無線機能の有無を書いていない。無線機能がある場合、日本で使うには技適が要る。海外から個人輸入する場合は、技適マークが付いたモデルかを購入前に確認したい。

**電源と保証。** 国内で使う電圧への対応、保証・修理の窓口は確認できていない。

待つなら、10月中旬の予約開始と、国内向けの案内を見てから決めるのがよい。多色印刷を今すぐ始めたいなら、国内の販売店が扱うBambu LabのA1 Comboのような、すでに買える多色対応機が選べる。
