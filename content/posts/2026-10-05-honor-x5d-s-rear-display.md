**Honor X5d s** は、6.78インチの本体の背面に2.01インチの小型ディスプレイを載せたエントリースマホだ。背面の画面は自撮りの確認、着信の通知、音楽の操作に使える。南アフリカでの価格は2,499ランドで、Stuff South Africaによれば10月7日から同国の店舗で発売される。

背面ディスプレイは、上位機種で見かける仕組みを低価格帯に下ろした形になる。2,499ランドは、Gizmochinaが約150ドルと換算している価格帯である。

## 仕様

| 項目 | 内容 |
| --- | --- |
| 前面ディスプレイ | 6.78インチ LCD、720×1576px、最大600nits |
| 背面ディスプレイ | 2.01インチ LCD、240×296px、タッチ対応 |
| SoC | Unisoc T610 |
| メモリ／ストレージ | 4GB（仮想メモリ4GB）／64GB、microSDで最大1TB |
| カメラ | 背面50MP（f/1.8）／前面5MP |
| バッテリー | 6,000mAh、15W有線充電（Honor公式は定格5,850mAhと記載） |
| OS | Android 16（Go edition） |
| 通信 | 4G LTE、デュアルSIM、Wi-Fi 5、Bluetooth 5.0、USB-C、3.5mmジャック |
| 防塵防水 | IP52 |
| サイズ／重量 | 168.3×78.5×8.72mm、約214g |
| 色 | Forest Green、Midnight Black |

前面のリフレッシュレートは、Gizmochinaが最大120Hzと書く一方、Honorの公式ページは90Hz対応と記している。報道と公式で食い違っており、確認できていない。

## 背面の画面でできること

背面ディスプレイの主役は自撮りだ。50MPの背面カメラで撮りながら、背面の画面で構図を確かめられる。前面の5MPカメラに頼らずに済む。着信の通知と音楽の再生操作も表示できる。

Stuff South Africaによれば、背面に育てるペットを表示する「Select a Pet」というテーマもある。触れると反応し、端末を使っていないときは眠る。実用というより遊びの機能で、使い続けるかどうかは実機で確かめるしかない。

## 日本から見るとどうか

掲載時点で、日本での発売や国内代理店の案内は確認できていない。「国内 発売」の日本語検索でも、国内の発表は出てこなかった。

技適の確認も取れていない。X5d sは4G、Wi-Fi、Bluetoothを積む無線機器で、日本の通信に使うには技適が前提になる。南アフリカ向けのモデルを個人輸入して国内で使えば、技適が無い状態での使用は電波法に抵触する。

対応バンドが日本の回線に合うかどうかも、公式の仕様からは確認できていない。

読者が取れる行動としては、国内向けの発売を待つか、背面ディスプレイにこだわらないなら国内正規品のエントリースマホを選ぶことになる。たとえば Amazon.co.jp で売られているmoto g06は、Android 15と6.9インチの画面を持つモデルで、技適も取得済みの国内版だ。背面画面は無いが、同価格帯で今日から使える。

なお、この記事の価格と発売日はすべて掲載時点のものである。実機のレビューは確認できていない。
