深圳のeスポーツ周辺機器ブランドRAWMが、光学式スイッチを採用した60%ゲーミングキーボード「Nyx60」を発表した。この価格帯のハイエンド競技用キーボードは、WootingやRazerが採用する磁気(ホールエフェクト)方式が主流だが、RAWMはあえて光でスイッチの押し込みを検知する方式を選び、「フルアルミボディで光学スイッチを採用するのは世界初」とうたう。Kickstarterでの先行予約開始は9月3日を予定している。

## スペックと価格

| 項目 | 内容 |
| --- | --- |
| レイアウト | 60% |
| スイッチ | 独自の光学式(Light-Guided Optical Switch)、精度0.01mm |
| 対応機能 | ラピッドトリガー、DKS、SOCD、Mod Tap |
| ポーリングレート | 最大8,000Hz |
| フレーム | CNC削り出しフルアルミ、トレイマウント、4層防振材 |
| キーキャップ | ポリカーボネート、Cherryプロファイル |
| タイピング角度 | 7° |
| MSRP | 199ドル |
| Kickstarter早期割引 | 99ドル($1デポジット登録者、2026年6月18日〜9月2日) |
| Kickstarter開始予定 | 2026年9月3日 |

RAWMによれば、磁気スイッチはセンサーが温度変化の影響を受けやすく、長時間の使用でアクチュエーションポイントがずれる「サーマルドリフト」が起きうるという。光学方式はこの影響を受けにくいというのがRAWMの主張で、公開している社内データでは55℃までほぼドリフトなく安定するとしている。ただしこれはRAWM自身が公開した比較であり、第三者による検証結果ではない。

基板は4層構造の防振PCBと放熱板を組み合わせ、8000Hzの高ポーリングレートを熱によるふらつきなく維持する設計とうたう。PCBキットとしても販売予定で、カスタムキーボードを組みたい層にも対応する。

## 日本から見るとどうか

**技適は論点にならない。** Nyx60はUSB Type-C接続の有線キーボードで、無線機能を積むという記載は確認できていない。無線を使わない有線の周辺機器は技適の対象外なので、Wi-FiやBluetoothを積む製品にありがちな「国内で電波を出せるか」という問題自体が生じない。

**日本語配列(JIS配列)への対応は確認できていない。** RAWMのページで確認できるのはUS配列のみで、日本語配列版が用意されるかどうかの記載はない。日本の自作キーボード愛好家の多くはUS配列に慣れているが、この点は購入前に確認したい。

**価格と輸入の手間。** Kickstarter早期割引の99ドルは、国内で流通する同クラスの磁気スイッチキーボード(Wooting 60HE v2は4万円台)よりかなり安い。ただしKickstarter経由の海外発送になるため、実際の到着額は関税・消費税・送料次第で変わる。クラウドファンディングである以上、これはまだ製品ではなく、量産や配送スケジュールが計画どおり進む保証もない。
